## Contrats techniques

Les fragments restent autonomes. La sémiologie cardiovasculaire est ajoutée au seul S01. Les quatre onglets de cours sont conservés. Les classes fermées, les identifiants préfixés par code et les fenêtres `data-pop` suivent le contrat des chapitres. Les figures scientifiques sont locales et accompagnées d'une introduction, d'une légende et d'une interprétation.

Une révision de contenu ne suffit pas à déclarer un cours entièrement audité. Les statuts d'achèvement existants ne sont pas augmentés automatiquement. Les modèles 3D servent à comprendre les repères de l'examen ; ils ne sont pas des reconstructions d'imagerie d'un patient.

## Validation reproductible

```bash
python3 build_front.py --all-fragments
python3 tests/audit_fragments.py
python3 tests/audit_sciences.py --out /tmp/medina-science-content.json
python3 test_v7.py --static I21 I25 I10 I50 I42 I48 I44 I47 I49 I46 I35 I34 I00 I30 I33 I40 Q21 I71 I80 I70 J45 J44 J18 I26 D84 M06 M32 T78 M31 A41
MEDINA_QA_OUT=/tmp/medina-navigation node tests/verify_s01_browser.cjs
MEDINA_QA_OUT=/tmp/medina-sciences-cs node tests/verify_sciences_cs.cjs
```

Les tests navigateur utilisent Playwright. Si nécessaire, installer `npm install --no-save playwright`, puis `npx playwright install chromium`. Le module `tests/browser_runtime.cjs` utilise en priorité le navigateur installé par Playwright, puis recherche Chromium ou Chrome dans le `PATH` et dans les emplacements habituels de macOS et Windows. `MEDINA_CHROMIUM_PATH` reste une surcharge facultative vers un exécutable existant. Une surcharge invalide produit une erreur explicite. Aucun chemin de l'environnement Codex n'est imposé à Claude. L'API utilisée est celle de la [documentation officielle Playwright](https://playwright.dev/docs/api/class-browsertype#browser-type-executable-path).

Les 71 contrôles de navigation ont été relancés avec ce module. Six vérifications complémentaires couvrent la surcharge valide ou invalide, la priorité du navigateur Playwright, la détection dans le `PATH`, un lancement réel sans surcharge et le message en l'absence de navigateur. [Résultats de portabilité](../../audits/SCIENCES_CS_2026-10-07/collaboration/browser-runtime-results.json). La découverte sous macOS et Windows est prévue par le code ; elle n'a pas été exécutée dans cette session Linux.
