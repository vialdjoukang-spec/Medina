La classification ne liste aucune exclusion pour G99 [S1]. Le tableau donne les sous-codes et les maladies causales que la CIM-10-GM 2024 y rattache.

Une gastroparésie diabétique se code donc E10.4† ou E11.4† avec G99.00*, et une myélopathie cervicarthrosique M47.1† avec G99.2* [S1].
