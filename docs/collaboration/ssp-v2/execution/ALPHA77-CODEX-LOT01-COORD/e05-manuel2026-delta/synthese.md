Dans le cadre hospitalier SpiGes, le chapitreXV prime pour la description
obstétricale lorsque ses conditions sont remplies. Les catégoriesO98–O99
nécessitent alors un code précisant la maladie. Les exemples du manuel
illustrent O99 tantôt en diagnostic principal, tantôt en diagnostic secondaire,
selon le séjour. Une affection sans relation avec la grossesse relève d'un
autre chemin. Le choix du diagnostic principal repose sur l'analyse du dossier
à la sortie ; le seul codeE05 d'une leçon ne permet pas ce choix.

Le rapprochement O99.2 et un codeE05 pertinent reste donc conditionnel à une
affection documentée et à l'applicabilité réelle de cette catégorie. Aucune
règle universelle grossesse+E05→O99.2 en diagnostic principal n'est attestée,
aucun exemple thyroïdien spécifique n'est inventé. Cette lecture ne certifie
ni remboursement, ni règle ambulatoire universelle, ni codage d'un cas individuel.
