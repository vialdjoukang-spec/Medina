# C95 — leucémie à cellules non précisées

[Ouvrir le cours autonome](C95-apercu-autonome.html), avec images originales et annotations françaises intégrées. Cette version reste sur sa branche réservée pour revue par Vial avant toute PR ou écriture sur main. Aucune certification médicale humaine n’est revendiquée.

Le cours distingue la catégorie administrative C95, le dossier incomplet et les leucémies aiguës de lignée ambiguë démontrées. Il développe critères OMS/ICC, diagnostic intégré, urgences, stratégies fondées sur les données disponibles, pharmacologie suisse et suivi. Les chiffres conservent population, période et limites.

- 14 points monographiques et 20 rubriques : [matrices et explications](coverage-final.md).
- Six sciences, dont neuf sections de sémiologie ; 52 fenêtres, 14 synthèses et cinq cas avec corrections.
- Quatre originaux humains licenciés CC BY 4.0, sept occurrences annotées ; quatre diagrammes causaux non anatomiques. [Provenance et droits](images-provenance.json).
- 32 entrées documentaires, dont sept fiches suisses, passages ciblés et réutilisations attribuées : [registre des lectures](recherche_C95/sources.json). Le résumé EBMT2026 reste explicitement une lecture de résumé.
- Statique, sciences, recherche VÉRITÉ, build S06, assemblage autonome et navigateur 1440/390 réussis : [reçu](verification.json), [navigation](browser-report-autonomous.json), [15 captures réellement inspectées](visual-inspection.json).
- Quatre auto-relectures attribuées : [MED, LANG, ordinateur et mobile](review-package/self-review.json). Leur mode `self_review` ne signifie pas revue indépendante.
- Les [empreintes finales](source-binding.json) lient les six surfaces, le glossaire, les originaux/attributions et l’aperçu. Les scripts de veille ne les renouvellent jamais.

La duplication d’une figure trop grande dans une fenêtre a été retirée ; l’original annoté reste dans Histologie. Le débordement des 52 fenêtres est désormais contrôlé. Les sigles hérités hors contexte ont été orientés vers les fenêtres locales, et les nombres décimaux ont été vérifiés après correction typographique. L’[incident de rendu et sa résolution](render-finding-before-final.json) est conservé.

Les diagrammes de cytométrie sont denses sur téléphone : consulter aussi l’original ou un écran plus large pour leurs axes fins. Le bouton Plan et les barres flottantes du moteur partagé peuvent masquer momentanément une portion pendant le défilement. Les tests utilisent une origine HTTP interceptée ; aucun déploiement ni test `file://` n’est prétendu.

Les limites complètes figurent dans le manifeste : incidence suisse propre C95 non établie, remboursement individuel non certifié, codage2024 daté, preuve limitée de certaines stratégies rares et absence de protocole prescripteur exhaustif. La base existante a été examinée avant remplacement ; les sources intégrales téléchargées restent dans le cache hors Git.

Les scripts éditoriaux assemblent un texte rédigé et relu ; ils ne réalisent pas une validation médicale autonome. `record_final_review.py` ne doit être exécuté manuellement qu’après relecture réelle de la version finale et des captures ; il n’appartient à aucune veille.
