23 lectures ciblées documentées, dont quatre informations professionnelles suisses de produits exacts. Les sources intégrales et extraits de travail restent dans le cache externe ; le ledger public contient des paraphrases et empreintes. Les images historiques OpenStax et les photomicrographies possèdent des licences propres vérifiées.

Les vérifications sont des auto-relectures IA, sans certification clinique ni validation humaine. L’incidence suisse globale de N00 n’est pas documentée par les sources lues ; elle n’est pas inventée. Le syndrome n’autorise pas une immunosuppression universelle. La FI Lasix, les limites pédiatriques de Norvasc et la distinction entre l’indication réglementaire d’Ospen et l’évolution d’une glomérulonéphrite établie sont explicites. KDIGO AKI a été lu par extraction fournisseur, sans prétendre avoir téléchargé le PDF direct. Le sédiment original reste limité à 567×337 pixels.

La copie conserve la navigation et les mentions natives héritées de publication provisoire. Le bouton flottant Plan et la barre fixe peuvent recouvrir une petite zone dans certaines captures ; le contenu reste accessible par défilement. Aucun déploiement public, PR ou changement de main. Les coûts et tokens réels indisponibles restent null.
