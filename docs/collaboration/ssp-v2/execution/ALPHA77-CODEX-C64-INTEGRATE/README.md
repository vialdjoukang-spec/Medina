# C64 — tumeur maligne du rein, à l’exception du bassinet

[Aperçu natif autonome](C64-apercu-autonome.html), ouvrable hors réseau avec cinq images originales incorporées. Cette livraison de branche ne constitue ni une intégration dans main ni une certification clinique.

Quatorze points monographiques, vingt rubriques Medina, six sous-onglets scientifiques et neuf sections sémiologiques. Vingt-sept enregistrements de lecture ciblée sur seize URL distinctes, dont huit informations professionnelles suisses exactes. Cinq originaux humains, dix occurrences et trente-trois repères HTML. Trente-sept fenêtres, dont quatorze synthèses, et quatre quiz originaux.

Les tests statiques, l’audit scientifique et les contrôles Chromium à 1440/390 pixels passent. Les images ont été mesurées après défilement et décodage ; fenêtres, navigation clavier et mode Livre 24 pixels ont été exercés, avec requêtes externes bloquées. Aucun déploiement public testé.

Le badge flottant du moteur partagé peut couvrir une légende sur une capture mobile ; le défilement permet sa lecture.
