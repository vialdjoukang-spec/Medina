Grossesse. Chez une femme enceinte, le diabète de malnutrition préexistant se code O24.2, « diabète sucré de malnutrition préexistant », et le diabète apparu pendant la grossesse O24.4 (CIM-10 OMS 2019 [S2] ; libellé CIM-10-GM non vérifié). Le gliclazide est contre-indiqué pendant la grossesse et l’allaitement (Diamicron MR [S14]). Les sources lues ne donnent aucune conduite propre au « type 5 » pendant la grossesse : la prise en charge suit celle du diabète préexistant.
