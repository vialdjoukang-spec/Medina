La classification distingue d’ailleurs les deux situations : la carence sans anémie relève du code E61.1, l’anémie ferriprive du code D50, qui exclut l’anémie aiguë après hémorragie (D62) [S11]. Ses sous-codes séparent l’anémie après pertes sanguines chroniques (D50.0), la dysphagie sidéropénique de Plummer et Vinson (D50.1), les autres formes (D50.8) et la forme non précisée (D50.9) [S11].
