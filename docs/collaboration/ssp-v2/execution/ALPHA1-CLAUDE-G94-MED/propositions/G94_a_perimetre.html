Aucune entité de G94.30 n’est développée par les sources lues ; l’encéphalopathie de Wernicke, enseignée ici comme urgence du diagnostic différentiel, possède son propre code E51.2, sans renvoi croix ni astérisque Dans la CIM-10-GM 2024, l’encéphalopathie de Wernicke se code E51.2, code autonome sans croix ; seule la forme humide du béribéri (E51.1†) renvoie à un astérisque, I98.8*. Le Wernicke n’est donc pas un exemple codé de G94.30 : la leçon le traite comme urgence de toute encéphalopathie secondaire. Autres affections du cerveau au cours de maladies classées ailleurs
