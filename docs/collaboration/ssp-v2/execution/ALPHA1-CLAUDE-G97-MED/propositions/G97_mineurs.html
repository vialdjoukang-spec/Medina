Renvoi obstétrical

Pendant la grossesse, le travail et le post-partum, la céphalée après anesthésie rachidienne ou péridurale se code dans le chapitre obstétrical de la CIM-10-GM 2024 : O29.4 pendant la grossesse, O74.5 pendant le travail et l’accouchement, O89.4 pendant le post-partum [S34]. Les vignettes obstétricales de ce cours relèvent donc de ces codes.
