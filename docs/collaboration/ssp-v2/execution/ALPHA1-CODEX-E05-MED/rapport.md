### Point de preuve sur l’unité d’agranulocytose

L’extraction du PDF ETA2018 écrit elle-même «<500/mL». Ce peut être une anomalie de glyphe/extraction ou une erreur du document; cet audit n’en établit pas l’origine graphique. Une copie de ce texte ne suffit pas à valider l’unité. La revue S8, texte intégral, écrit explicitement500/µL dans la définition et dans le diagnostic médicamenteux. Le consensus EHA2023 S9 appelle «sévère» une neutropénie<0,5×10⁹/L et réserve son terme générique «agranulocytose» à<0,2×10⁹/L. Cette distinction est conservée : le seuil500/µL est celui utilisé dans la toxicité sous antithyroïdien, et non une fusion de toutes les définitions.

## Réserves ouvertes

La matrice de20 rubriques est dans `recherche.md`. Les points suivants empêchent une validation finale de la leçon entière :

- Le protocole de crise recourt à la JTA2016, identifiée comme japonaise. Sa lecture historique n’a pas été refaite. Les conversions entre méthimazole et carbimazole, la formulation d’iodure hospitalière, le support hémodynamique et les doses hors FI demandent une validation hospitalière suisse explicite. Aucune dose nouvelle n’est proposée ici.
- Les FI d’iodure131, Brevibloc, Solu-Cortef et Prednisone Streuli n’ont pas été rouvertes pour toutes les doses et durées enseignées. Le schéma EUGOGO et la FI du mycophénolate demandent une preuve complète. La valeur1g/j de méthylprednisolone n’est pas une frontière démontrée d’innocuité en dessous de laquelle les pulses seraient sans risque.
- Les seuils CAS/EUGOGO, critères JTA, recommandations pédiatriques2022, normes Risch (y compris grossesse), directives OFSP de radioprotection et conditions suisses de remboursement n’ont pas été revalidés intégralement sur leur texte actuel. Les résumés «200MBq imposent48h» doivent aussi garder la dérogation OFSP déjà décrite dans le corps.
- Le TRAK à18–22semaines est conditionné par sa positivité initiale dans ETA2018, recommandation36; le cours le présente parfois de façon systématique. La perte de cette condition et les autres règles de surveillance de grossesse sont à harmoniser avec la source applicable.
- Les affirmations absolues sur nodule chaud/non-ponction, les mécanismes biochimiques très détaillés, la «protection» par sexe/contraception et les fréquences de chaque signe ont été lus dans le cours, mais ne sont pas tous indépendamment confirmés. Le compte rendu ARS MEDICI n’est pas une étude épidémiologique nationale.

HAS2023 a été tentée mais renvoie HTTP503. Les sources qui n’ont pas pu être ouvertes ne figurent pas comme lues. Les preuves historiques sont conservées sans promotion en validation actuelle.
