Pour l’ensemble des CUP, les facteurs pronostiques sont l’état général, les marqueurs d’inflammation systémique (protéine C réactive, neutrophiles), l’albuminémie, la LDH, les comorbidités, le nombre de métastases et la présence de métastases hépatiques [S4]. Ces facteurs décrivent un groupe ; ils ne permettent pas de prédire la survie d’un patient donné [S4]. Dans le CUP cervical, l’extension extracapsulaire abaisse la survie à 5 ans de 82 % à 57 % [S4].
