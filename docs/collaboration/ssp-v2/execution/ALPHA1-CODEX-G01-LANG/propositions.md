## Réserves médicales

MED-01 : Exclusivité de que : les trois critères d’imagerie résument-ils vraiment toutes les raisons médicales de différer une ponction ? Aucun critère ajouté ou supprimé.

MED-02 : La fenêtre MONALISA décrit une association observationnelle non causale, puis cette fenêtre utilise contre-indication. Harmonisation médicale requise ; vocabulaire de contre-indication laissé inchangé.

MED-03 : Préciser le groupe de référence du HR pour que le sens de la comparaison soit lisible. Aucun renversement du rapport effectué.

MED-04 : Portée universelle de aucun diagnostic ; l’auteur voulait-il les diagnostics discutés ? Ne pas réduire cette portée sans arbitrage.

MED-05 : Le tableau comporte sept lignes, dont une procalcitonine entre les groupes. Préciser sa place et vérifier la portée de communs à toute méningite ; nombres inchangés.

MED-06 : Le verbe autorisée paraît réglementaire, alors que la fenêtre attribue ce choix à une recommandation. Vérifier l’information professionnelle suisse et distinguer recommandation/autorisation sans simple retouche linguistique.

MED-07 : Unité absente après 0,125, également dans les critères pharmacologiques. Aucune unité inventée.
