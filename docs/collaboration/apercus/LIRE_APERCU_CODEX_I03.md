# Consulter les dix cours prioritaires I-03

Le fichier `codex-i03-10-cours-20261009.html` contient l'aperçu interactif de travail Infectiologie : A41, B24, B18, A54, A53, B50, A04, A69, A15 et A16. Les contenus, fenêtres et polices sont embarqués. Aucun cours n'est présenté comme validé médicalement ou injecté dans le canon ; les deux audits de Claude restent requis.

Sur GitHub, ouvrir le fichier puis cliquer **Download raw file**. Conserver l'extension `.html`, puis l'ouvrir dans un navigateur. Si la politique du navigateur interdit les fichiers locaux, placer le fichier dans un dossier et lancer depuis ce dossier `python3 -m http.server 8765`, puis ouvrir `http://localhost:8765/codex-i03-10-cours-20261009.html`.

Les onglets, quiz et fenêtres ont été testés avec Chromium via HTTP. L'environnement de capture géré interdit le protocole `file://` (`ERR_BLOCKED_BY_ADMINISTRATOR`) : l'ouverture directe locale n'a donc pas pu y être testée. Les captures et animations réelles sont dans `../captures/codex-i03-a16-20261009/`, avec celles d'A15 et A69 dans leurs dossiers respectifs.
