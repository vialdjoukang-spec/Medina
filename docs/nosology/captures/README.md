Ouvrir `captures-medina.html` pour les 22 fragments sur ordinateur et mobile. Télécharger `captures-medina.zip` et extraire son contenu pour consulter la galerie localement. Les PNG individuels se trouvent dans `captures/`.

46 captures réelles du navigateur, 9 octobre 2026 : 22 vues ordinateur (1 440 × 1 100), 22 vues mobile (390 × 1 200), une coquille vide I20.0 et le portail global. Les cours, sous-leçons et versions préexistants sont préservés. Les trois jauges par fragment affichent leur pourcentage : pathologies fréquentes, Examen fédéral et avancement global.

Les étoiles indiquent une correspondance pédagogique PROFILES / SSP documentée. Leur exhaustivité comme liste officielle de maladies exigibles ne peut pas être certifiée par PROFILES seul. Voir `../README.md` pour les sources et limites.
