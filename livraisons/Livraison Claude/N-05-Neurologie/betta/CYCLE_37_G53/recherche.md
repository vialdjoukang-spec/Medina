- Codes voisins à distinguer : G51.- maladies du nerf facial (VII) et G52.- maladies des autres nerfs crâniens, qui codent l'atteinte comme maladie propre [S1].
- Question clinique de l'examen : devant une **névralgie faciale après zona** ou une **atteinte de plusieurs nerfs crâniens**, identifier la maladie causale (zona, infection, sarcoïdose, tumeur) car le traitement est celui de la cause [S11][S12][S14]. Dans une série de 979 patients hospitalisés avec ≥ 2 nerfs crâniens atteints, la **tumeur** était la cause la plus fréquente (305 cas, plus d'un quart), ce qui impose un diagnostic rapide [S25].

## 1. Définitions

- **Névralgie post-zostérienne (NPZ/NPH)**, définition opérationnelle des essais Shingrix : douleur associée au zona cotée ≥ 3/10, persistant ou apparaissant **plus de 90 jours** après le début de l'éruption (Zoster Brief Pain Inventory) [S8].
- **Neuroborréliose de Lyme possible / probable / confirmée** [S11, §3.10] :
  - possible : tableau typique (atteinte de nerfs crâniens, méningite/méningoradiculite, déficits focaux) + IgG et/ou IgM anti-Borrelia sériques (la sérologie peut être encore négative très tôt) + LCR non disponible + autres causes écartées ;
  - probable : idem + syndrome inflammatoire du LCR (pléiocytose lymphocytaire, dysfonction de la barrière hémato-LCR, synthèse intrathécale d'immunoglobulines) ;
  - confirmée : idem + synthèse intrathécale d'anticorps spécifiques (index anticorps IgG et/ou IgM positif) ou culture/PCR positive dans le LCR.
- **Neurosarcoïdose** (critères consensuels 2018) : possible (pas de confirmation histologique), probable (granulome confirmé hors système nerveux), définie (confirmation histologique dans le système nerveux) ; principe clé : exclure infection et néoplasie [S14][S15].
- **Méningite chronique** : signes d'inflammation méningée persistant ≥ 4 semaines sans résolution spontanée [S14].
- **Métastases leptoméningées (ML) EANO–ESMO** [S12] :
  - type I (confirmé) : cytologie du LCR ou biopsie leptoméningée positive ; IA linéaire, IB nodulaire, IC linéaire + nodulaire, ID hydrocéphalie ou IRM normale ;
  - type II (clinique + imagerie, antécédent de cancer, autres diagnostics envisagés, LCR négatif ou équivoque) : probable = signes cliniques typiques + IRM typique (IIA–IIC) ; possible = IRM typique sans signes typiques, ou signes typiques avec IRM normale ou hydrocéphalie seule ; absence de preuve = signes atypiques seuls avec IRM normale → ne pas poser le diagnostic.
  - nodule mesurable : ≥ 5 × 5 mm dans deux plans [S12].

## 2. Classifications utiles

- Par sous-code CIM (tableau §0) [S1].
- Neuroborréliose : précoce (symptômes < 6 mois ; méningoradiculite douloureuse avec parésie faciale uni- ou bilatérale = **syndrome de Bannwarth** ; méningite chez l'enfant) versus tardive (< 3 % des cas présumés ; encéphalomyélite progressive sur mois/années) [S11].
- Neurosyphilis : précoce (méningite syphilitique de la syphilis secondaire, surtout dans l'année suivant l'infection, avec atteinte des nerfs **VIII, VII, III**, parfois du nerf optique) ; méningovasculaire ; tardive (tabès, paralysie générale) [S10, §4.2].
- Neurosarcoïdose : formes cliniques — atteinte des nerfs crâniens, méningite chronique/hydrocéphalie, lésions parenchymateuses, myélite, système nerveux périphérique, hypothalamo-hypophysaire, vasculaire [S14].
- ML : types I/II et profils IRM A (linéaire), B (nodulaire), C (mixte), D (hydrocéphalie ou normale) [S12] ; ces sous-types sont pronostiques (type I plus défavorable que type II, P = 0,002) [S13].

## 3. Épidémiologie

- **Atteinte de plusieurs nerfs crâniens** (979 patients, hôpital municipal, États-Unis ; série personnelle) [S25] : nerfs les plus touchés VI (565), VII (466), V (353), III (339) ; sièges : sinus caverneux (252), tronc cérébral (217), nerfs individuels (182) ; causes : tumeur (305), maladie vasculaire (128), traumatisme (128), infection (102), Guillain-Barré et Fisher (91) ; récidive rare (43 cas), surtout diabète (14), causes inconnues spontanément résolutives (14), sinusite caverneuse idiopathique (10).
- **Zona/NPZ** : dans ZOE-50 (≥ 50 ans), incidence de NPZ sous placebo 0,6/1000 personnes-années ; dans l'analyse groupée ZOE-50/70 (≥ 70 ans), 1,2/1000 personnes-années [S8]. La fréquence et la sévérité du zona et de ses complications sont plus élevées à partir de 65 ans [S3]. Les douleurs neuropathiques chroniques (dont NPZ) touchent 6,9–10 % de la population générale [S21, résumé].
- **Neuroborréliose** : manifestation neurologique dans 3–15 % des borrélioses de Lyme [S11]. Taux de tiques infectées en Suisse 5–7 % selon la région ; densité de tiques infectées 2 à 58 pour 100 m² en Suisse ; en Suisse romande, risque d'infection après piqûre un peu < 5 % ; en Allemagne, séroconversion 2,6–5,6 % et maladie 0,3–1,4 % des piqûres [S11]. Pas de chiffres fiables d'incidence par pays européen [S11].
- **Neurosarcoïdose** : 5–15 % des sarcoïdoses ; manifestation inaugurale dans 50–70 % ; neurosarcoïdose isolée 22 % [S14]. Incidence de la sarcoïdose 1–40/100 000/an, la plus élevée en Europe du Nord (11–24/100 000) [S14]. Cohorte espagnole (342 sarcoïdoses) : neurosarcoïdose 8,5 %, incidence annuelle 1,1/1 000 000 ; atteinte des nerfs crâniens 24,1 % (+ 10,3 % avec céphalée chronique) [S17, résumé]. Cohorte indienne (48) : neuropathie crânienne = présentation la plus fréquente (47,9 %) [S26, résumé].
- **Métastases leptoméningées** : à évoquer surtout dans les cancers du **sein, du poumon et le mélanome** ; métastases cérébrales concomitantes 36–66 % (sein), 66–82 % (poumon), 69–87 % (mélanome) [S12].
- **Neurosyphilis** : séquelles chez 41,8 % de 142 patients, dont paralysies de nerfs crâniens 15,2 % et troubles visuels 11,8 % [S10].

## 4. Mécanismes (normal → pathologique)

- **Zona → NPZ** : le valaciclovir (ester de l'aciclovir) est converti en aciclovir, phosphorylé par la thymidine kinase virale du VZV puis par des kinases cellulaires ; le triphosphate inhibe l'ADN-polymérase virale et stoppe l'élongation de l'ADN viral ; la sélectivité vient de l'enzyme virale présente seulement dans les cellules infectées [S4]. La durée de la douleur zostérienne aiguë est abrégée, notamment chez les sujets âgés [S4]. Le vaccin prévient la NPZ **en prévenant le zona** ; un effet propre sur la NPZ chez les vaccinés ayant fait un zona n'a pas pu être démontré [S8].
- **Neuroborréliose** : inflammation méningoradiculaire ; LCR avec plasmocytes, lymphocytes activés et dysfonction de barrière ; cellularité moyenne 170–220/µl (6 à 1100/µl) ; synthèse intrathécale d'IgG dans 70–80 % (bandes oligoclonales) ; l'index anticorps spécifique devient positif vers la **2e semaine** et est détectable chez > 99 % ensuite ; il peut être négatif dans 10–30 % si symptômes < 6 semaines et chez l'enfant avec parésie faciale ; **CXCL13** du LCR augmente précocement mais n'est pas spécifique (neurosyphilis, méningite tuberculeuse, lymphome du SNC) [S11].
- **Neurosyphilis** : la méningite syphilitique précoce lèse les nerfs crâniens au sein d'une inflammation méningée ; la forme méningovasculaire associe vascularite et méningite [S10].
- **Neurosarcoïdose** : granulomes non nécrosants ; cellules épithélioïdes (dérivées des macrophages) sécrétant ACE et TNF-α ; TNF-α crucial pour la formation du granulome, d'où la cible thérapeutique ; réponse polarisée CD4 Th1/Th17.1 ; ratio CD4/CD8 élevé dans le LCR dans plusieurs séries ; héritabilité 39–66 % (études scandinaves) [S14]. Neuropathie optique par compression granulomateuse, hypertension intracrânienne ou névrite optique [S14].
- **Métastases leptoméningées** : dissémination tumorale dans les espaces sous-arachnoïdiens ; atteinte des nerfs II, III, IV, VI (diplopie, troubles visuels), VII (paralysie faciale), VIII (hypoacousie) ; atteinte spinale 34–52 % ; blocs de circulation du LCR [S12].
- **Brivudine** : son métabolite (bromovinyluracile) inhibe **irréversiblement la dihydropyrimidine-déshydrogénase (DPD)** → accumulation potentiellement mortelle de 5-FU et autres fluoropyrimidines ; la DPD se rétablit 18 jours après la dernière dose [S27].

## 5. Causes (par sous-code)

- **G53.0** : zona (B02.2†) avec névralgie dans le territoire d'un nerf crânien ; inclut l'inflammation du **ganglion géniculé** après zona et la névralgie trigéminale post-zostérienne [S1].
- **G53.1** (infections) :
  - virus responsables de paralysies de nerfs crâniens : **VZV, HSV, CMV, VIH, FSME (encéphalite à tiques), oreillons, poliovirus, VHC** [S9, tableau syndromes] ;
  - **neuroborréliose** : tous les nerfs crâniens sauf l'olfactif ; nerf facial dans > 80 % des atteintes crâniennes, bilatéral dans ~1/3 ; aussi VI, rarement VIII, II (névrite optique, œdème papillaire), III, IV, V, IX–XII [S11] ;
  - **neurosyphilis** : nerfs VIII, VII, III, nerf optique ; atteinte oculaire (uvéite postérieure, panuvéite) et otologique (hypoacousie, déficit vestibulaire), plus fréquente chez les personnes vivant avec le VIH pour l'atteinte oculaire [S10].
- **G53.2** (sarcoïdose) : neuropathies crâniennes chez **55 %** des neurosarcoïdoses ; nerf facial 24 %, optique 21 %, trijumeau 12 %, plusieurs nerfs 28 % ; **syndrome de Heerfordt** = paralysie faciale + parotidite + uvéite + fièvre ; la sarcoïdose est une cause majeure de **diplégie faciale** [S14].
- **G53.3** (tumeurs) : métastases leptoméningées des tumeurs solides (sein, poumon, mélanome) [S12] ; tumeur = cause la plus fréquente des atteintes multiples dans la série de Keane [S25]. Effet indésirable immunologique des inhibiteurs de points de contrôle : cas de neuropathies crâniennes multiples sous pembrolizumab, cortico-sensibles [S28, cas clinique].
- **G53.8** (autres) : sources lues limitées à des cas cliniques et revues pour : artérite à cellules géantes (III + VI) [S29, cas], PIDC avec atteinte crânienne (III, VII, X, XII ; 1/4 en phase aiguë) [S30, résumé] ; diabète comme cause de neuropathie crânienne récidivante [S25].

## 6. Anamnèse

- Zona : délai depuis l'éruption (traitement antiviral à débuter **au plus tard dans les 72 h**) [S4] ; localisation céphalique/ophtalmique [S9] ; immunodépression [S3] ; chimiothérapie par fluoropyrimidines (contre-indication de la brivudine) [S27].
- Borréliose : piqûre de tique, érythème migrant, **douleurs radiculaires** nocturnes peu sensibles aux antalgiques ; déficits neurologiques 1–4 semaines après le début des douleurs chez 3/4 des patients [S11].
- Syphilis : exposition sexuelle, statut VIH, symptômes oculaires ou auditifs [S10].
- Sarcoïdose : sarcoïdose connue (poumons 57 %, yeux 20 %, ganglions 18 %, peau et articulations 18 %), symptômes systémiques ; 84 % ont une atteinte extraneurologique au cours de l'évolution [S14].
- Cancer connu (sein, poumon, mélanome), céphalées, nausées/vomissements, troubles cognitifs, troubles de la marche, douleurs radiculaires ou cervico-dorsales [S12].

## 7. Examen clinique

- Examen systématique de chaque nerf crânien ; otoscopie pour la paralysie faciale (lésions vésiculeuses du zona) [S22, résumé].
- Paralysie faciale : rechercher la bilatéralité (sarcoïdose, neuroborréliose, Guillain-Barré, Melkersson-Rosenthal) [S14] ; dans la neuroborréliose le goût peut être épargné [S11].
- Neuropathie optique sarcoïdosique : moins souvent douloureuse que la névrite optique classique (20–30 % vs > 60 %), plus souvent bilatérale [S14].
- ML : signes méningés, radiculaires, déficits de nerfs crâniens multiples [S12].

## 8. Examens complémentaires

### 8.1 Liquide céphalorachidien
- Neuroborréliose : voir §4 ; ponction lombaire indispensable pour classer probable/confirmée [S11]. La sérologie seule ne doit être demandée qu'en cas de suspicion clinique suffisante, en deux étapes (dépistage + confirmation) [S11]. L'index anticorps ne sert pas à suivre l'efficacité du traitement (peut rester positif des mois/années) [S11].
- Neurosarcoïdose : leucocytes mononucléés élevés 58 % (5 à 1571/mm³), protéines élevées 63 %, hypoglycorachie 14 %, index IgG 40 %, bandes oligoclonales 46 %, ACE élevée 46 % [S14]. Versus SEP (Zurich) : cellularité > 30/µl (RV+ 7,2), Qalb > 10 × 10⁻³ (RV+ 66,4), absence de bandes oligoclonales spécifiques (RV+ 11,5), lactate élevé (RV+ 23,0) ; combinaison d'un de ces critères + **réaction MRZ négative** : sensibilité et spécificité > 92 % [S18, résumé].
- ML [S12] : pression d'ouverture > 200 mm H₂O 21–42 % ; leucocytes > 4/mm³ 39–77,5 % ; protéines > 500 mg/l 56–91 % ; glucose bas 22–38 % ; cytologie positive au diagnostic 60,5–83 % ; prélever idéalement > 10 ml (au moins 5 ml), analyser dans les 30 min ; **ponction après l'IRM** ; répéter une fois si cytologie négative ou équivoque ; attendre ~14 jours après chirurgie du SNC.
- Syphilis : en cas de symptômes ophtalmologiques ou otologiques, la démarche spécifique est décrite [S10, §957–961] (détail non extrait : voir Lacunes).

### 8.2 Imagerie
- ML : IRM 1,5 T ou de préférence 3 T, gadolinium 0,1 mmol/kg, **cerveau et moelle** le même jour ou à ≤ 7 jours ; IRM normale malgré LCR positif : 26 % (poumon), 4 % (sein) [S12].
- Neurosarcoïdose : IRM cérébrale anormale 79 %, spinale 50 % ; rehaussement méningé 46 %, des nerfs crâniens 26 % ; recherche d'une atteinte systémique par **TDM thoracique haute résolution**, puis **TEP-FDG** si négative (détection 70 % et 78 %) ; biopsie extraneurale (EBUS-TBNA) [S14].

### 8.3 Biomarqueurs sériques (sarcoïdose)
- ACE sérique : sensibilité 75 % non traité, 35 % traité ; lysozyme 46 % ; ACE du LCR sens./spéc. 67 %/67 % [S14]. Neuropathie optique sarcoïdosique : ACE sens. 21,4 %, spéc. 97 % ; lysozyme sens. 33,3 %, spéc. 98 % → inutiles comme dépistage [S19, résumé]. sIL-2R du LCR > 150 pg/ml : précision 93 % contre maladies non infectieuses seulement [S14].

## 9. Diagnostic différentiel

- Paralysie faciale : 25–40 % des paralysies faciales périphériques ne sont pas idiopathiques ; examen neurologique, otoscopie et ponction lombaire sont les outils clés [S22, résumé].
- Diplégie faciale : sarcoïdose, neuroborréliose, Guillain-Barré, Melkersson-Rosenthal [S14].
- Imitateurs de neurosarcoïdose : lymphome (syndrome sarcoïdose-lymphome), gliome, SEP, MOGAD, pachyméningite hypertrophique (granulomatose avec polyangéite, polyarthrite rhumatoïde, IgG4), hypotension intracrânienne spontanée, méningiomes multiples, histiocytose langerhansienne, Erdheim-Chester, déficit immunitaire commun variable ; réactions sarcoïdosiques médicamenteuses (anti-TNF, interférons, inhibiteurs de points de contrôle) [S14].
- CXCL13 élevé : neuroborréliose, mais aussi neurosyphilis, tuberculose méningée, lymphome du SNC [S11].
- Atteinte multiple : PIDC [S30], Guillain-Barré/Fisher [S25], artérite à cellules géantes [S29].

## 10. Urgences

- **Zona ophtalmique** : aciclovir **intraveineux** [S9]. Zona céphalique compliqué/encéphalite à VZV : aciclovir IV (patients immunodéprimés surtout) ; foscarnet si aciclovir insuffisant [S9].
- **Hydrocéphalie** de la neurosarcoïdose : obstructive dans 90 %, intervention neurochirurgicale dans 80–90 % ; surveiller la taille ventriculaire [S14]. ML : dérivation du LCR — 83 % d'amélioration clinique sur 190 patients ; infections 5 %, hématome/hygroma sous-dural 13 % [S12].
- Neuropathie optique (neurosarcoïdose) : pronostic réservé, 40 % s'améliorent sous corticoïdes [S14].

## 11. Prise en charge (référentiels suisses puis européens)

### 11.1 G53.0 — zona céphalique et NPZ
- Antiviral : **valaciclovir 1000 mg 3×/j pendant 7 jours**, débuter le plus tôt possible, au plus tard dans les 72 h (zona ophtalmique inclus) ; adaptation rénale : ClCr 30–49 → 1000 mg 2×/j ; 10–29 → 1000 mg 1×/j ; < 10 → 500 mg 1×/j [S4].
- Alternatives citées par la directive DGN/SNG : aciclovir 5 × 800 mg/j per os 7–10 jours, famciclovir 3 × 250–500 mg, **brivudine 125 mg/j** 7 jours (début < 72 h) [S9]. Brivex® (Suisse) : zona en phase précoce chez l'**immunocompétent adulte** ; contre-indiqué chez l'immunodéprimé et si 5-FU/capécitabine/flucytosine récents, actuels ou prévus dans les 4 semaines (interaction potentiellement mortelle) [S27].
- Paralysie faciale avec infection à VZV : virostatique **obligatoire** ; prednisolone pour la forme idiopathique (25 mg 2×/j 10 jours, ou 60 mg/j 5 jours puis décroissance de 10 mg/j ; NNT = 10) ; protection cornéenne [S22, résumé].
- Douleur neuropathique (NPZ), information professionnelle suisse :
  - **prégabaline** (Lyrica®) : indiquée dans les douleurs neuropathiques périphériques et centrales ; 150 mg/j (2–3 prises), ↑ 300 mg/j après 3–7 jours, max. 600 mg/j après 7 jours de plus ; dans la NPZ, 150, 300 et 600 mg/j supérieures au placebo ; répondeurs (–50 %) 22–26 %, 26–28 %, 38–50 % vs 9–20 % placebo ; effets fréquents : vertiges 30,7 %, somnolence 16,4 % ; risque de dépression respiratoire et de décès liés aux opioïdes en association (aOR 1,68) [S5] ;
  - **gabapentine** : indiquée chez l'adulte dans la neuropathie diabétique et la NPZ ; J1 300 mg, J2 600 mg, J3 900 mg/j ; entretien 900–3600 mg/j en 3 prises ; adaptation si ClCr < 80 ml/min ; risque de syndrome DRESS [S6] ;
  - **capsaïcine 8 % patch** (Qutenza®) : douleurs neuropathiques périphériques de l'adulte, 60 min pour la NPZ, jusqu'à 4 patchs, répétable tous les 90 jours (minimum 60) ; **ne pas appliquer près des yeux ni des muqueuses** (limite pour la NPZ faciale) [S7].
  - EFNS 2010 : niveau A pour tricycliques, prégabaline, gabapentine, tramadol et opioïdes, lidocaïne topique et capsaïcine patch (selon conditions) ; association tricyclique–gabapentine et gabapentine–opioïde utile (niveau A) [S20, résumé]. Revue allemande 2016 : tricycliques, IRSN et anticonvulsivants calciques en première intention (NNT 3,5–7,7) [S21, résumé].
- Prévention (Suisse, Plan de vaccination 2026) : **Shingrix®** 2 doses à 0 et 2 mois pour tous les **≥ 65 ans** immunocompétents (vaccination complémentaire), y compris après Zostavax® (intervalle ≥ 2 mois) ; **≥ 50 ans** avec immunodéficience actuelle ou prévisible (VIH, insuffisance rénale terminale/dialyse, biologiques, azathioprine, méthotrexate faible dose, corticothérapie d'entretien faible dose, PR, asthme sévère/BPCO, diabète de type 1 mal contrôlé, autres maladies auto-immunes) ; **≥ 18 ans** avec immunodéficience sévère ou immunosuppression forte (chimiothérapie, greffe de CSH ou d'organe, inhibiteurs de JAK, VIH CD4 < 200/µl) : 0 et (1–)2 mois ; pas de sérologie VZV préalable ; attendre la guérison d'un zona aigu ; la vaccination **ne traite ni le zona ni la NPZ** [S3]. Efficacité contre la NPZ : 100 % (IC 77,1–100) ≥ 50 ans ; 88,8 % (68,7–97,1) ≥ 70 ans ; 89,3 % après greffe de CSH [S8].

### 11.2 G53.1 — infections
- **Neuroborréliose précoce** : doxycycline, ceftriaxone, céfotaxime ou pénicilline G ; durée **14 jours** (preuve Ia) ; doxycycline orale équivalente aux β-lactamines IV (RR 0,98 [0,68–1,42]) ; limite d'âge de 8 ans pour la doxycycline supprimée ; **pas de corticoïdes** ajoutés pour une parésie faciale dans une neuroborréliose probable/confirmée (↓↓, consensus 17/17) ; pas de prophylaxie par doxycycline après piqûre en Europe [S11][S31, résumé]. Pronostic : récupération complète de la parésie faciale en 1–2 mois dans la plupart des cas, séquelles/synkinésies 5–10 % ; 88 % bons résultats à 12 mois (77 Bannwarth) [S11].
- **Neurosyphilis** (directive DGN avec SNG, 2026) : **pénicilline G IV** 4 × 6 MUI/j, 5 × 5 MUI/j ou 3 × 10 MUI/j pendant **14 jours** (minimum 10) ; alternative **ceftriaxone 2 g/j IV 14 jours** (pas de dose de charge de 4 g) ; même schéma pour syphilis oculaire et otosyphilis et toute coinfection VIH ; traitement antiépileptique concomitant si antécédent de crises (crises sous fortes doses de pénicilline) [S10].
- Infections virales à tropisme crânien : aciclovir IV dans les infections à VZV avec atteinte du SNC [S9].

### 11.3 G53.2 — neurosarcoïdose
- Prise en charge par équipe multidisciplinaire ; pas d'essai randomisé spécifique [S14].
- 1re ligne : corticoïdes — prednisone 1 mg/kg puis décroissance sur des mois, ou méthylprednisolone 1000 mg/j IV 3 jours + prednisone orale plus faible (p. ex. 20 mg/j) ; évolution favorable 71 % (161/227) ; rechute 33 % (neurologique 23 %) sous corticoïdes seuls ; ~15 % à faible charge/récupération spontanée [S14].
- 2e ligne : **méthotrexate** (agent de 2e ligne de premier choix selon la directive européenne ERS 2021), azathioprine, MMF ; réponse globale 55 % [S14][S16, résumé].
- 3e ligne/phénotypes sévères : **infliximab** (amélioration 72 %, stabilisation 21 %, échec 7 % ; infections 10–39 %), adalimumab, rituximab, cyclophosphamide ; tendance à une approche par phénotype/sévérité avec anti-TNF précoce [S14]. Cohorte espagnole : 82,4 % de rémission complète à 12 mois sous biologique [S17, résumé].
- Pronostic : paralysie faciale généralement favorable ; névrite optique réservée ; un tiers seulement asymptomatique après traitement [S14]. Atteinte cardiaque associée chez 12 % d'une cohorte de neurosarcoïdose → bilan cardiaque [S32, résumé, cohorte américaine].

### 11.4 G53.3 — maladies tumorales (métastases leptoméningées des tumeurs solides, EANO–ESMO 2023)
- Intrathécal pour types IA/IC (III,B), voie ventriculaire préférée ; méthotrexate 10–15 mg 2×/sem × 4 sem puis hebdomadaire × 4 sem puis mensuel + acide folinique ; cytarabine 10 mg ; thiotépa 10 mg ; trastuzumab intrathécal (HER2+) ; pémétrexed intrathécal (CPNPC EGFR muté, réponse 85 %) [S12].
- Systémique pour types B/C ; thérapies ciblées (osimertinib EGFR, céritinib ALK) ; nivolumab (mélanome) [S12].
- Radiothérapie focale stéréotaxique pour lésions nodulaires/symptomatiques ; panencéphalique 30 Gy/10 fractions ou 20 Gy/5 sans bénéfice de survie démontré ; craniospinale : myélosuppression grade 3–4 jusqu'à 37 % [S12].
- Survie médiane : sein 3,8–5,4 mois ; poumon 4,2–8,1 ; mélanome 4,8 ; mixte 3 ; 20 % des cancers du sein > 1 an ; facteurs favorables : âge jeune, bon état général, faible charge tumorale, pas de cellules tumorales dans le LCR, pas de bloc, traitement systémique et intrathécal [S12].

## 12. Suivi

- ML : examen neurologique tous les 2 mois pendant 6 mois puis tous les 3 mois ; IRM cerveau + moelle toutes les 6–12 semaines ; LCR toutes les 6–12 semaines sous intrathécal ; réponse cytologique complète = négativation maintenue ≥ 4 semaines ; ne changer le traitement que si l'aggravation persiste > 2 semaines [S12].
- Neuroborréliose : l'index anticorps ne suit pas l'efficacité ; amélioration en semaines à mois après 10–14 jours d'antibiotique [S11].
- Neurosarcoïdose : surveillance de la taille ventriculaire ; surveillance des effets des corticoïdes (ostéoporose, diabète, glaucome, cataracte, infections, HTA) [S14] ; critères de rechute en cours de standardisation [S14].
- Neurosyphilis : séquelles fréquentes (41,8 %) [S10].

## 13. Situations particulières

- **Immunodépression** : zona plus fréquent et compliqué (surtout déficit cellulaire) → vaccination dès 18 ou 50 ans selon le profil [S3] ; brivudine contre-indiquée [S27] ; formes oculaires de syphilis plus fréquentes chez les personnes vivant avec le VIH [S10] ; VIH avec CD4 < 200 et zona [S3].
- **Chimiothérapie par fluoropyrimidines** + zona : brivudine interdite (4 semaines avant/après) [S27] ; Shingrix 1re dose idéalement ≥ 2 semaines avant la chimiothérapie [S3].
- **Insuffisance rénale** : adapter valaciclovir [S4] et gabapentine [S6].
- **Enfant** : neuroborréliose avec méningite fréquente ; index anticorps parfois négatif en cas de parésie faciale ; doxycycline possible sans limite d'âge de 8 ans [S11]. Gabapentine non recommandée chez l'enfant pour la douleur neuropathique [S6].
- **Grossesse** : valaciclovir — exposition à l'aciclovir environ doublée en fin de grossesse versus aciclovir oral [S4] ; brivudine contre-indiquée [S27].

## 14. Critères formels (pour l'îlot final `div.alert`)

- NPZ : douleur ≥ 3/10 > 90 jours après l'éruption [S8].
- Neuroborréliose possible/probable/confirmée [S11, §3.10] (voir §1).
- Neurosarcoïdose possible/probable/définie [S14][S15] (voir §1).
- Métastases leptoméningées type I/II, probable/possible [S12] (voir §1).
- Codage : code † de la maladie causale + G53.x* [S1].

## 15. Paramètres clés (pour `div.key`)

- Valaciclovir 1000 mg 3×/j 7 j, < 72 h [S4].
- Shingrix : ≥ 65 ans ; ≥ 50 ans immunodéficients ; ≥ 18 ans immunodéficience sévère ; 2 doses à 0 et 2 mois [S3].
- Neuroborréliose : nerf VII > 80 % des atteintes crâniennes, bilatéral ~1/3 ; antibiotique 14 jours ; pas de corticoïdes [S11].
- Neurosyphilis : pénicilline G IV 18–30 MUI/j ou ceftriaxone 2 g/j, 14 jours [S10].
- Neurosarcoïdose : nerfs crâniens 55 % (VII 24 %, II 21 %) ; prednisone 1 mg/kg ; MTX 2e ligne ; infliximab [S14].
- ML : cytologie positive 60,5–83 % au diagnostic ; répéter la PL une fois ; IRM avant PL ; survie médiane 3–8 mois [S12].
- Atteinte multiple des nerfs crâniens : tumeur > 25 % des causes [S25].
