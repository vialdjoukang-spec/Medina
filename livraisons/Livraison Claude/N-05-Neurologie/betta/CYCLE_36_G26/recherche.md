# G26 — Syndromes extrapyramidaux et troubles de la motricité au cours d'affections classées ailleurs (N-05-Neurologie)

Dossier de recherche, cycle Betta 36, leçon 2 (agent C36-A4-NEUR, recherche Opus 5.5). Consultation : 15.10.2026.
Chaque fait est suivi de son identifiant `[Sx]`, détaillé dans `sources.json`. Rien n'a été ajouté de mémoire. Ce qui n'a pas été lu figure sous « Lacunes ».

## 0. Question clinique et logique de codage (CIM-10-GM 2024)

- G26 porte le marqueur **astérisque (*)** : c'est un code de **manifestation**, qui accompagne le code (†) de la maladie causale [S2]. Le libellé allemand est « Extrapyramidale Krankheiten und Bewegungsstörungen bei anderenorts klassifizierten Krankheiten » ; la CIM-10-GM 2024 **ne liste ni inclusion, ni exclusion, ni sous-code** sous G26* [S1].
- Codes voisins à distinguer [S1] : **G21** parkinsonisme secondaire (G21.0 syndrome malin des neuroleptiques, G21.1 autre parkinsonisme médicamenteux, G21.2 autres agents externes, G21.3 postencéphalitique, G21.4 vasculaire, G21.8, G21.9) ; **G22*** parkinsonisme au cours d'affections classées ailleurs (inclusion : parkinsonisme syphilitique A52.1†). Le parkinsonisme d'une maladie classée ailleurs relève donc de G22*, les **autres** troubles du mouvement (chorée, ballisme, dystonie, myoclonies, tremblement, syndromes mixtes) de G26* [S1] (déduction de la structure du bloc ; voir Lacunes).
- Sous-codes couverts : **aucun** (catégorie sans subdivision) [S1][S2].
- Question clinique de l'examen : devant un **trouble du mouvement d'installation aiguë ou subaiguë**, surtout **asymétrique**, chercher une **cause acquise et réversible** (métabolique, endocrinienne, auto-immune, infectieuse, médicamenteuse, structurelle) avant une cause génétique ou dégénérative [S3, Tab. 1][S9].

## 1. Définitions

- **Chorée** : mouvements brefs, irréguliers, sans but, passant de façon imprévisible d'une partie du corps à l'autre [S6, Chorea and dyskinesias].
- **Dystonie** : contractions musculaires soutenues ou intermittentes causant des mouvements ou postures anormaux [S6, Dystonia].
- **Myoclonie** : secousses très brèves, en « décharge » [S6, Myoclonus].
- **Parkinsonisme** : défini par la bradykinésie ; le parkinsonisme « atypique » répond mal à la lévodopa [S6, Parkinsonism].
- **Hémichorée-hémiballisme hyperglycémique / « striatopathie diabétique »** : hyperglycémie associée à une chorée/ballisme et/ou à des anomalies striatales en imagerie ; nomenclature encore ambiguë [S7].
- **Dégénérescence hépatocérébrale acquise (DHCA)** : syndrome neurologique chronique des hépatopathies avancées, surtout avec shunts porto-systémiques [S11][S12].
- Diagnostics différentiels de la chorée [S3, « Wichtige Differenzialdiagnosen »] : épilepsie focale ; **tics** (précédés d'une sensation impérieuse et brièvement répressibles, ce qui est atypique pour la chorée) ; **akathisie** (difficile à distinguer, souvent induite par neuroleptiques et surtout tétrabénazine) ; myoclonus-dystonie.

## 2. Classification étiologique des troubles du mouvement « au cours d'affections classées ailleurs »

Énumération de la directive DGN/SNG [S3, §3.2] (sélection des causes non génétiques) :

| Groupe | Causes citées [S3] |
|---|---|
| Auto-immunes / paranéoplasiques | chorée de Sydenham (ASLO, anti-DNase B) ; **LED** ; **syndrome des antiphospholipides** ; chorée gravidique (souvent LED/SAPL) ; SEP ; Behçet ; encéphalites auto-immunes (NMDAR, GAD65, CASPR2, LGI1, IgLON5, CRMP-5, Hu, Yo, Ma2…) ; SREAT ; maladie cœliaque ; Takayasu ; polyangéite microscopique |
| Infectieuses | encéphalopathie VIH ; encéphalites virales (oreillons, rougeole, VZV, HSV, échovirus) ; vMCJ ; endocardite bactérienne ; neurobrucellose ; **neurosyphilis** ; **neuroborréliose** ; toxoplasmose cérébrale ; cryptococcose ; neurocysticercose ; **maladie de Whipple** ; PESS ; grippe A ; SARS-CoV-2 |
| Structurelles | infarctus ischémique ou hémorragique ; tumeurs ; abcès ; lésions démyélinisantes ; myélinolyse ; neurosarcoïdose ; cavernome ; moyamoya |
| Métaboliques, endocriniennes, toxiques | **hyperglycémie non cétosique** (hyperintensité T1 putaminale) ; hypoglycémie ; hypo/hypernatrémie ; hypocalcémie ; **hypoparathyroïdie** (calcifications des noyaux gris) ; **hyperthyroïdie** ; porphyrie aiguë intermittente ; **insuffisance hépatique** dont DHCA ; insuffisance rénale ; CO, manganèse, mercure, thallium, organophosphorés ; carence en B12 ; Wernicke |
| Hématologiques et autres | **polyglobulie de Vaquez** ; thrombocytémie essentielle ; chorée « post-pump » après chirurgie cardiaque ; sidérose superficielle |
| Médicamenteuses | antagonistes dopaminergiques (dont métoclopramide), lévodopa et agonistes, antiépileptiques, antagonistes calciques (flunarizine, cinnarizine, vérapamil), lithium, tricycliques, contraceptifs oraux, psychostimulants, etc. (relèvent plutôt de codes propres : voir Lacunes) |

- Les mouvements anormaux d'origine auto-immune se présentent surtout comme chorée ou dystonie (Sydenham, encéphalite des noyaux gris anti-D2) ; LED et SAPL peuvent donner une chorée [S14].
- Maladie de Wilson : manifestation neurologique en **parkinsonisme, dyskinésie choréo-athétosique, dystonie et/ou syndrome cérébelleux** ; signes pyramidaux rares, troubles sensitifs jamais [S4, §2.2]. Formes cliniques : pseudosclérotique (tremblement de repos, d'attitude, intentionnel, « flapping », dysarthrie scandée, ataxie, nystagmus), pseudo-parkinsonienne (hypo/bradykinésie, rigidité, dysarthrie, tremblement), arythmique-hyperkinétique (choréo-athétose, dystonie) [S4, Tab. 1].

## 3. Épidémiologie

- **Chorée asymétrique/hémichorée** (243 sources) : cause la plus fréquemment rapportée = **hémichorée/hémiballisme hyperglycémique non cétosique**, puis Sydenham, SAPL et chorée médicamenteuse ; la grande majorité des formes asymétriques est **acquise** [S9].
- **Striatopathie diabétique** (176 patients publiés) : rapport H:F = 1:1,7 ; âge moyen 67,6 ± 15,9 ans (8–92) ; diabète de type 2 dans 96,6 %, dont 17 % découverts à cette occasion ; glycémie moyenne 414 mg/dl, HbA1c moyenne 13,1 % ; hémichorée/hémiballisme dans 88,1 % ; chorée bilatérale 9,7 % [S7].
- Revue systématique (214 cas) : 65,3 % de femmes ; âge médian 71 ans, 67,3 % > 65 ans ; 67,3 % des cas publiés en Asie (biais de publication possible) ; diabète connu 78,1 % ; chorée révélatrice du diabète chez 61 patients ; glycémie médiane 379 mg/dl ; HbA1c médiane 13,7 % [S8].
- **Chorée hyperthyroïdienne** (28 cas publiés 1990–2022) : âge médian 23 ans (8–78) ; 22 femmes ; mouvements symétriques dans 17 cas [S10].
- **Wilson** : âge de manifestation de 5 à 45 ans, pic 13–24 ans ; avant la puberté prédominance hépatique, après la puberté prédominance neurologique ; manifestation neurologique après 10 ans ; présentation psychiatrique dans près de 10 % [S4, §2.1–2.2]. Risque familial : fratrie ≈ 25 %, enfants ≈ 0,5 % [S4, Empfehlungen].
- Aucune donnée d'incidence suisse lue (lacune).

## 4. Mécanismes (normal → pathologique)

- **Hyperglycémie** : l'hyperglycémie orienterait le métabolisme cérébral vers des voies anaérobies avec baisse du cycle de Krebs ; le cerveau utiliserait alors des substrats alternatifs comme le **GABA**, ce qui désinhiberait le noyau sous-thalamique et les noyaux gris ; ce modèle n'explique pas les cas qui persistent ou s'aggravent après normalisation glycémique (hypothèse d'un mécanisme proche de l'aggravation rétinienne après correction rapide) [S8]. Quatre études anatomopathologiques sur six montrent une **hémorragie** comme pathogénie probable [S7]. Une microangiopathie striato-pallidale est suggérée par l'association à la rétinopathie : rétinopathie présente chez 9/13 patients documentés, avec hyperkinésie plus persistante ; résolution spontanée ou à faibles doses chez les patients sans rétinopathie [S13].
- **Hyperthyroïdie** : hypothèses d'effet central direct de la thyrotoxicose (sans lésion structurelle démontrée post mortem), d'hypersensibilité dopaminergique nigrostriatale (acide homovanillique du LCR abaissé) et d'altération des récepteurs adrénergiques ; un hypermétabolisme bilatéral des noyaux gris en TEP-FDG a été rapporté [S10].
- **Wilson** : maladie autosomique récessive du gène **ATP7B** ; défaut d'excrétion biliaire du cuivre et d'incorporation dans la céruloplasmine ; accumulation toxique de cuivre dans le foie puis le cerveau [S4, §2.1, Was gibt es Neues]. Plus de 800 variants pathogènes, sans corrélation génotype-phénotype établie [S4].
- **DHCA** : accumulation de substances toxiques (ammoniac, **manganèse**) et neuro-inflammation [S11] ; facteur de risque principal = shunts porto-systémiques [S12].
- **Auto-immunité** : anticorps contre antigènes de surface (NMDAR, LGI1, CASPR2) → réponse à l'immunothérapie habituellement bonne ; anticorps onconeuronaux intracellulaires → syndromes multisystémiques progressifs [S6][S3].

## 5. Anamnèse

- Rechercher [S3, §3.3] : **antécédents familiaux**, **anamnèse médicamenteuse**, maladies associées (diabète, thyroïde, hépatopathie, LED/SAPL, grossesse, cancer).
- Indices orientants :
  - début aigu/subaigu chez un diabétique âgé mal équilibré → striatopathie diabétique [S7][S8] ;
  - signes de thyrotoxicose apparus des semaines à des années avant les mouvements [S10] ;
  - convulsions, dysautonomie, ataxie, troubles psychiatriques → encéphalite anti-NMDAR [S6] ; rechute choréique 2 à 6 semaines après une encéphalite herpétique → anti-NMDAR [S6] ;
  - crises dystoniques facio-brachiales brèves (< 3 s), jusqu'à plusieurs centaines par jour, âge médian ≈ 66 ans → **anti-LGI1** ; hyponatrémie, bradycardie épisodique = drapeaux rouges [S6] ;
  - diarrhée prolongée avec amaigrissement et myoclonies → anti-DPPX [S6] ;
  - hépatopathie, troubles psychiatriques, adulte jeune → Wilson [S4].
- Tout trouble extrapyramidal inexpliqué, surtout **jusqu'à 45 ans**, doit faire évoquer une maladie de Wilson [S4, Empfehlungen].

## 6. Examen clinique

- La chorée est souvent plus visible pendant l'entretien et sous tension émotionnelle ; l'examen formel peut au contraire la réduire par co-contraction agonistes-antagonistes [S3, §3.3].
- Statut neurologique, neuropsychologique, psychiatrique et **internistique** [S3, §3.3].
- **Latéralité** : une chorée asymétrique oriente vers une cause acquise (structurelle, métabolique) [S3, Tab. 1][S9].
- Wilson : **anneau de Kayser-Fleischer** quasi pathognomonique surtout avec signes neurologiques, mais son absence n'exclut pas le diagnostic (souvent absent chez l'enfant et dans la forme hépatique) ; rarement présent dans d'autres cholestases chroniques [S4, p. 11].
- Paranéoplasique anti-Ma2 : phénotype de type PSP (paralysie supranucléaire verticale > horizontale), troubles hypothalamiques, troubles du sommeil [S6].

## 7. Examens complémentaires

### 7.1 Laboratoire (chorée sporadique) [S3, Tab. 1]
Bilan de routine dont tests hépatiques, CK (± frottis à la recherche d'acanthocytes), **vitamine B12**, ferritine, ASLO, anti-DNase B, **céruloplasmine, cuivre sérique et urinaire de 24 h**, ANA, ENA, anti-ADN double brin, ANCA, FR, anti-gliadine, anticorps antineuronaux (Hu, Yo, Ma, CRMP-5/CV2, NMDAR, GAD, IgLON5, LGI1), **anticorps antiphospholipides/anticardiolipine**, **TSH**, anti-TPO, TRAK, **parathormone**, érythropoïétine et hématocrite (Vaquez), dépistage syphilis, Borrelia, **VIH**, test de grossesse si indiqué. Glycémie, natrémie et calcémie font partie des causes métaboliques à exclure [S3, §3.2]. Selon le cas : métaux lourds, dépistage toxicologique, ponction lombaire [S3, §3.3].

### 7.2 Imagerie
- **IRM** (TDM si contre-indication) pour exclure une cause symptomatique et chercher des signes évocateurs [S3, §3.3] :
  - hyperglycémie non cétosique : hyperintensité T1, surtout putaminale [S3] ; atteinte putaminale isolée ou putamino-caudée la plus fréquente ; discordance TDM/IRM chez environ 1/6 ; chorée et imagerie non concomitantes chez 1/10 [S7] ; anomalies des noyaux gris dans 89,2 %, IRM normale dans 5,2 % [S8] ;
  - Wilson : signal anormal T1 (putamen, pallidum, substance noire, noyau rouge) et cérébelleux, atrophie ; signe du « **panda géant** » mésencéphalique en T2 ; l'imagerie documente l'atteinte mais ne pose pas le diagnostic [S4, imagerie][S3] ;
  - DHCA : hyperintensité **T1 bilatérale du pallidum** ; lésions T2 des pédoncules cérébelleux moyens dans la forme ataxique [S11] ;
  - calcifications des noyaux gris : hypoparathyroïdie, calcification familiale primaire, mitochondriopathie [S3, Tab. 1] ;
  - encéphalite paranéoplastique CRMP-5/Hu : hypersignaux FLAIR substance blanche, noyaux gris, temporaux internes ; atrophie caudée possible (imitation de Huntington) [S6] ; LGI1 : hypersignaux des noyaux gris dans ≈ 40 % des crises dystoniques facio-brachiales [S6].
- TEP-FDG (cas particuliers) : hypermétabolisme des noyaux gris dans Sydenham et encéphalite auto-immune ; hypoperfusion striatale controlatérale dans l'hémichorée hyperglycémique [S3, §3.3].

### 7.3 Maladie de Wilson : biochimie et score [S4]
- Cuivre urinaire > 100 µg/24 h (enfant : seules des valeurs < 40 µg/24 h sont sûrement normales) ; céruloplasmine < 20 mg/dl (typiquement < 10) ; cuivre sérique < 70 µg/dl ; cuivre libre > 10 µg/dl (REC > 18,5 %) ; cuivre hépatique > 250 µg/g de poids sec [S4, p. 11].
- La céruloplasmine baisse en cas de malnutrition, d'insuffisance hépatique ou de fuite protéique et monte avec les œstrogènes et l'inflammation : une baisse isolée ou limite n'est ni sensible ni spécifique [S4].
- Constellation suffisante : **anneau de Kayser-Fleischer + céruloplasmine < 10 mg/dl** [S4].
- **Score de Leipzig** (Tab. 2) : KF 0/2 ; symptômes neuropsychiatriques 0/1/2 ; anémie hémolytique Coombs négative 0/1 ; cuivre urinaire 0/1/2 ; cuivre hépatique −1/1/2 ; rhodanine 0/1 ; céruloplasmine 0/1/2 ; ATP7B 0/1/4. **≥ 4 : diagnostic très probable ; 2–3 : possible ; 0–1 : improbable** [S4]. L'EASL-ERN 2025 recommande le score de Leipzig complété par le cuivre échangeable relatif [S5, résumé].

## 8. Diagnostic différentiel
- Maladie de Huntington (chorée héréditaire la plus fréquente ; ≈ 8 % sans antécédent familial) et autres chorées génétiques [S3, Tab. 1].
- Épilepsie focale, tics, akathisie, myoclonus-dystonie [S3].
- Encéphalite anti-NMDAR chez l'enfant peut être confondue au début avec Sydenham [S6]. LGI1/CASPR2 et MCJ : myoclonies et hypersignaux corticaux/noyaux gris possibles dans les deux ; LCR de base souvent normal [S6].

## 9. Urgences et situations à ne pas manquer
- Hémichorée aiguë chez le diabétique : correction glycémique [S7][S8].
- Encéphalites auto-immunes : diagnostic rapide crucial, car une intervention précoce améliore le pronostic à long terme et peut sauver la vie [S14] ; les crises dystoniques facio-brachiales répondent préférentiellement à l'immunothérapie, dont la précocité préviendrait le déficit cognitif [S6].
- Syndrome malin des neuroleptiques (rare) sous tétrabénazine : altérations psychiques, rigidité, hyperthermie, dysautonomie, CK élevées → arrêt immédiat [S15].
- Wilson : insuffisance hépatique aiguë → transplantation selon le « New Wilson Index » [S4].

## 10. Prise en charge (Suisse)

### 10.1 Principe
Traiter la **cause** ; la thérapie symptomatique accompagne [S3][S6][S14].

### 10.2 Causes spécifiques
- **Striatopathie diabétique** : succès du contrôle glycémique seul 25,7 %, avec antichoréiques ajoutés 76,2 % ; récidive 18,2 % ; halopéridol = antichoréique le plus utilisé [S7]. Dans la revue de 214 cas, la récupération ne différait pas entre insuline seule et insuline associée (p = 1,0) ; aucun traitement standard établi [S8]. Formes réfractaires : aucune conduite sourcée retenue (voir Lacunes, point 4).
- **Hyperthyroïdie** : amélioration en semaines à mois avec la normalisation thyroïdienne chez la plupart ; propranolol (soulagement partiel) ou antidopaminergiques en appoint [S10].
- **Auto-immun** : immunothérapie (empirique ou consensus d'experts, faute d'essais randomisés) ; LGI1 : réponse « exquise » aux corticostéroïdes ; recherche et exérèse d'une tumeur sous-jacente essentielles ; symptomatiques : déplétants dopaminergiques, antagonistes dopaminergiques, GABAergiques [S6][S14].
- **DHCA** : antiparkinsoniens avec amélioration clinique ; transplantation hépatique sans amélioration neurologique chez 2 patients ; rôle de la transplantation controversé [S12].
- **Wilson** [S4] :
  - Initiation : **chélateur à dose progressive** pour les formes hépatiques et neurologiques symptomatiques ; montée lente pour éviter une **aggravation neurologique paradoxale (parfois irréversible)** par mobilisation trop rapide du cuivre.
  - D-pénicillamine : 150 mg/j au départ ; dans les formes neurologiques, paliers toutes les 1–2 semaines ; suspendre l'escalade en cas d'aggravation ; entretien 600–1500 mg/j (max 1800) ; pyridoxine 20 (–40) mg/j ; cuprurie sous traitement > 500 µg/24 h.
  - Trientine : en Allemagne, Autriche et **Suisse**, AMM en 2e ligne après intolérance à la D-pénicillamine [S4]. FI suisse Cuprior® : 450–975 mg/j de trientine base en 2–4 prises ; dans les formes neurologiques, augmentation lente avec suivi toutes les 2–3 semaines ; aggravation neurologique possible en début de chélation par excès de cuivre libre [S18].
  - Zinc (3 × 50 mg de zinc élément/j ; répartition en 3 prises essentielle) : sujets présymptomatiques et entretien des patients stables [S4].
  - Objectif : cuprurie basale (après 2 jours de pause) < 100 µg/j [S4].
  - Amélioration attendue en 6 à 24 mois ; au-delà de ≈ 2 ans, traitement symptomatique (L-dopa, clonazépam, tiapride, antidépresseurs, antipsychotiques, toxine botulique) [S4, §4.4].
  - Transplantation hépatique : envisageable à titre exceptionnel dans les formes neurologiques réfractaires [S4].

### 10.3 Traitement symptomatique de la chorée (statut suisse)
- Directive DGN/SNG : **tiapride** (antagoniste D2/D3) en première intention envisageable (meilleur profil psychique et extrapyramidal), **tétrabénazine** (inhibiteur VMAT2) si tiapride insuffisant, en monothérapie ou combinaison ; pas d'étude comparative ; alternatives : olanzapine, autres atypiques [S3, §4.1.3].
- **FI Tiapridal®** : indication suisse = chorée de Huntington sévère de l'adulte et tics sévères ; Huntington : jusqu'à 1200 mg/j au début, entretien 300–600 mg/j ; contre-indiqué avec la lévodopa, chez le parkinsonien, en cas de tumeur prolactino-dépendante [S16].
- **FI Xenazine®** : indication suisse = mouvements hyperkinétiques de la maladie de Huntington ; 12,5 mg × 3/j, +12,5 mg/j tous les 3–4 jours jusqu'à 100 mg/j ; inefficace après 7 jours à dose maximale → bénéfice improbable ; contre-indications : dépression, syndrome parkinsonien, insuffisance hépatique modérée à sévère, IMAO (intervalle ≥ 14 jours), réserpine, allaitement ; CYP2D6 (génotypage avant > 50 mg/j), QTc + ≈ 8 ms ; effets très fréquents : dépression, somnolence, parkinsonisme, akathisie [S15].
- **FI Haldol®** (oral) : pas d'indication pour une chorée secondaire ; Huntington léger à modéré en cas d'échec d'autres traitements ; contre-indiqué en cas de syndrome parkinsonien ou QTc long [S17].
- → Dans une chorée « au cours d'affections classées ailleurs », ces médicaments sont **hors indication suisse** (constat déduit des FI [S15][S16][S17]).

## 11. Suivi
- Wilson : surveillance à vie, cuivre urinaire de 24 h environ tous les 1–2 ans ; IRM au début, à 2 ans, puis tous les 4–6 ans ou immédiatement en cas d'aggravation neurologique ; dépistage génétique obligatoire de la fratrie et des enfants ; vaccination hépatites A et B [S4]. Cuprior® : suivi au moins deux fois par an [S18].
- Striatopathie diabétique : récidive 18,2 % [S7] ; rétinopathie possiblement associée à une évolution plus persistante → intérêt du fond d'œil (hypothèse) [S13].

## 12. Situations particulières
- **Grossesse** : chorée gravidique, souvent liée au LED/SAPL [S3]. Wilson : ne pas interrompre le traitement ; réduire la dose de chélateur aux 2/3 au 3e trimestre ; risque tératogène D-pénicillamine ≈ 5 % [S4].
- **Enfant** : Sydenham, anti-NMDAR, anti-D2 (décrits seulement chez l'enfant) [S6] ; Wilson diagnostiqué en général dès 4–5 ans en cas de suspicion [S4].
- **Sujet âgé** : striatopathie diabétique (âge médian 71 ans) [S8] ; anti-LGI1 (âge médian ≈ 66 ans) [S6].

## 13. Critères formels (pour le dernier îlot)
- Codage : G26* = manifestation ; code † de la maladie causale en premier [S1][S2].
- Wilson : score de Leipzig ≥ 4 = diagnostic très probable ; KF + céruloplasmine < 10 mg/dl = constellation suffisante [S4].
- Aucun critère diagnostique formel validé de la striatopathie diabétique n'a été lu (nomenclature ambiguë) [S7].

## Lacunes
1. **Paires † / G26* officielles** : la CIM-10-GM 2024 n'énumère aucune inclusion ; l'index alphabétique (quelles maladies se codent avec G26*, p. ex. Wilson E83.0, LED, hyperthyroïdie) n'a pas été lu. La frontière G22* (parkinsonisme) / G26* (autres troubles) est déduite de la structure du bloc. Les troubles médicamenteux se codent probablement hors G26* (G21.1, G25.-) : non vérifié.
2. **Aucune source suisse primaire spécifique** (Swiss Medical Forum, SNG) sur les troubles du mouvement secondaires n'a été trouvée ; seule l'approbation SNG de S3 et la coordination suisse de S4 rattachent le dossier à la Suisse. Aucune donnée épidémiologique suisse.
3. **EASL-ERN 2025 (Wilson)** : texte intégral inaccessible (403) ; seul le résumé est utilisé [S5].
4. Striatopathie, hyperthyroïdie, DHCA : uniquement séries de cas et revues (souvent résumés) ; aucune recommandation européenne dédiée trouvée. Le cas de stimulation cérébrale profonde (PMID 42410315) n'a été lu qu'en résumé et n'est pas retenu.
