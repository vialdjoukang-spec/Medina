## 0. Question clinique et périmètre

Devant un syndrome parkinsonien, la question pratique est : **une maladie générale ou une lésion cérébrale identifiable explique-t-elle ce parkinsonisme, et peut-on la traiter ?** Beaucoup de parkinsonismes secondaires sont réversibles quand la cause est supprimée ; d'autres bénéficient d'un traitement symptomatique [S5]. Une imagerie anormale chez un patient parkinsonien suggère une étiologie secondaire et impose une démarche propre [S5].

**Codage CIM-10-GM 2024** [S1, S2, S3] :

| Élément | Contenu lu |
|---|---|
| Code | **G22\*** — « Syndrome parkinsonien au cours de maladies classées ailleurs » (OFS) ; « Parkinson-Syndrom bei anderenorts klassifizierten Krankheiten » (BfArM) [S1, S2] |
| Sous-codes | **Aucun** : G22\* est une catégorie à 3 caractères sans subdivision [S1] |
| Inclusion | « Parkinson-Syndrom bei Syphilis (A52.1†) » [S1] |
| Exclusions, notes | Aucune sous G22\* [S1] |
| Règle astérisque | Les codes \* désignent la **manifestation** ; ils ne doivent **jamais être utilisés seuls**, toujours avec un code dague (†, étiologie) ou un autre code primaire. Exemple BfArM : A17.9† G99.8\* [S3] |

- Conséquence pour le cours : G22\* n'est pas une maladie mais une **manifestation** ; le cours porte sur les maladies causales dont le parkinsonisme est une expression. La seule causalité nommée par la classification est la **syphilis (A52.1†)** [S1].
- Voisins : G20 = maladie de Parkinson ; G21 = parkinsonisme secondaire (médicaments, agents externes, post-encéphalitique, vasculaire) [S1] — traité dans la leçon G21 du même cycle.
- **Lacune** : la règle suisse de codage (Manuel de codage OFS) pour les couples †/\* n'a pas été lue ; seule la règle BfArM (allemande) est citée [S3]. Le rattachement CIM de chaque cause listée ci-dessous à G22\* (vs G21.8 ou code étiologique seul) n'est pas vérifié à la source, sauf pour la syphilis.

## 1. Définitions

- **Parkinsonisme** : bradykinésie associée à une rigidité, à un tremblement de repos, ou aux deux [S5] ; critères MDS identiques [S18].
- **Parkinsonisme secondaire (acquis)** : parkinsonisme d'une cause identifiable, non génétique et non dégénérative ; la cause iatrogène est la plus fréquente (traitée en G21) [S5].
- **Différence sémiologique utile** : les formes métaboliques et toxiques donnent une bradykinésie et une rigidité **symétriques**, avec trouble de la marche marqué et peu ou pas de tremblement de repos ; les lésions expansives et vasculaires sont plutôt **unilatérales** et peuvent comporter un tremblement de repos [S5]. Rigidité, bradykinésie et troubles de la marche sont plus fréquents que le tremblement de repos ; d'autres mouvements anormaux ou signes neurologiques associés orientent vers la cause [S5].

## 2. Classification étiologique (cadre de lecture)

D'après la revue de Ljubljana [S5] (formes médicamenteuses exclues) :

| Groupe | Exemples lus |
|---|---|
| Vasculaire | parkinsonisme post-AVC aigu ; parkinsonisme vasculaire progressif ; fistules durales artério-veineuses [S5] |
| Hydrocéphalie | obstructive ; à pression normale idiopathique (HPN) [S5] |
| Lésions expansives | tumeurs (compression, infiltration gliale ou lymphomateuse, craniopharyngiome mésencéphalique) ; hématome sous-dural [S5] |
| Métabolique | dégénérescence hépatocérébrale acquise ; encéphalopathie urémique diabétique ; hypocalcémie/hypoparathyroïdie et calcifications des noyaux gris ; myélinolyse osmotique ; hyperglycémie non cétosique [S5] ; **maladie de Wilson** [S6–S9] |
| Hypoxo-ischémique | nécrose pallidale et striatale [S5] |
| Toxique | méthanol, CO, cyanure, disulfure de carbone/disulfirame, manganèse, MPTP, drogues [S5] (codage G21.2, voir leçon G21) |
| Infectieux | encéphalite japonaise, West Nile, VIH, SARS-CoV-2, *Mycoplasma pneumoniae*, neurocysticercose, toxoplasmose, cryptococcose, HHV-6, Creutzfeldt-Jakob [S5] ; **neurosyphilis** [S1, S11] |
| Immun | encéphalites paranéoplasiques et auto-immunes (anti-Ma2, anti-Ri, CRMP5, NMDAR, LGI1, CASPR2, IgLON5) ; lupus, syndrome des antiphospholipides, Sjögren ; sclérose en plaques [S5] |

- **Lacune** : la syphilis n'est pas mentionnée dans la revue de Ljubljana [S5] ; la ligne directrice neurosyphilis [S11] ne mentionne pas le parkinsonisme en propre (seuls « Zungentremor » et « mimisches Beben » figurent dans la paralysie générale). Aucune source lue ne décrit la sémiologie spécifique du parkinsonisme syphilitique.

## 3. Épidémiologie

- **Genève (étude populationnelle suisse, diagnostics 2003–2012)** : 1235 patients ; 80 % parkinsonismes dégénératifs, **20 % non dégénératifs** ; parmi ceux-ci : médicamenteux 43,4 %, vasculaire 37 %, HPN 5,1 %, parkinsonisme psychiatrique ou fonctionnel 3,8 % [S4]. Le reste (≈ 10 %) n'est pas détaillé dans le résumé — **Lacune** (part des causes « maladies classées ailleurs »).
- Après AVC : 56 séquelles motrices anormales sur 1500 AVC, dont 6 parkinsonismes ; 1 parkinsonisme sur 11 infarctus striataux parmi 622 AVC consécutifs [S5].
- Dégénérescence hépatocérébrale acquise : **1–2 %** des insuffisances hépatiques chroniques ou shunts porto-systémiques [S5].
- Calcifications des noyaux gris : 0,2–2 % des scanners de routine, près de 40 % à 70 ans ; une calcification pallidale isolée est habituellement sans portée [S5]. Hypoparathyroïdie (223 cas revus) : parkinsonisme = trouble moteur le plus fréquent, délai diagnostique moyen ≈ 10 ans [S5].
- Neurocysticercose : parkinsonisme = trouble moteur le plus fréquent chez 590 patients, mais < 3 % [S5].
- Lupus : ≈ 40 cas publiés ; syndrome des antiphospholipides : 9 cas [S5].
- **Maladie de Wilson** : prévalence génétique ≈ 1/30 000, hétérozygotes 1/40 à 1/90 ; prévalence clinique en France ≈ 1,5/100 000 [S7] ; Revue Médicale Suisse : ≈ 1/30 000 [S10].
- **Creutzfeldt-Jakob en Suisse** : 10 à 15 cas par an, tous de forme classique ; aucun cas de variant déclaré à ce jour [S12].
- **Syphilis** : Allemagne 2024 : 9519 cas, 11,2/100 000 [S11]. **Lacune** : incidence suisse de la syphilis et de la neurosyphilis non lue (OFSP).

## 4. Mécanismes : du normal au pathologique

- **Normal** : le parkinsonisme naît de l'atteinte du circuit nigrostrié (substance noire pars compacta → striatum) ou des noyaux gris en aval (pallidum, putamen) [S5]. Plus de 90 % des localisations lésionnelles provoquant un parkinsonisme sont connectées au mésencéphale, aux noyaux gris centraux, au cortex cingulaire antérieur et au cervelet ; la connectivité au **claustrum** est la plus sensible et spécifique [S5].
- **Règle pharmacologique clé** : la **lévodopa** est surtout efficace quand la lésion est **présynaptique nigrostriée isolée** (récepteurs striataux intacts) ; elle l'est rarement quand la lésion touche le striatum ou le pallidum (post-synaptique) [S5]. Exemples : hématome sous-dural, tumeur par compression, CO, lupus, syndrome des antiphospholipides → lévodopa habituellement inefficace [S5].
- **Wilson** : déficit du transporteur **ATP7B** (gène sur le chromosome 13) → baisse de l'excrétion biliaire du cuivre → accumulation hépatique puis cérébrale [S10]. Dans le cerveau, cuivre multiplié par ≈ 10 (tissu et LCR) ; toxicité mitochondriale, stress oxydatif, atteinte membranaire, pontage de l'ADN, inhibition enzymatique ; tamponnement initial par astrocytes et oligodendrocytes, puis rupture de la barrière hémato-encéphalique et démyélinisation ; lésions maximales dans le **putamen** [S8]. Le parkinsonisme wilsonien combine lésions pré- et post-synaptiques nigrostriées [S8].
- **Dégénérescence hépatocérébrale acquise** : accumulation de **manganèse**, surtout pallidale [S5].
- **Hydrocéphalie obstructive** : parkinsonisme rare, mois ou années après la présentation, souvent après dysfonctions répétées de dérivation [S5].
- **Tumeurs** : compression (masse, œdème), infiltration, compression mésencéphalique, déconnexion des circuits noyaux gris–cortex, hydrocéphalie ; réversibilité si compression, pas si infiltration [S5].
- **Fistule durale artério-veineuse** : hypoperfusion des noyaux gris ou trouble du drainage veineux profond [S5].

## 5. Causes principales — fiches

### 5.1 Neurosyphilis (A52.1† G22\*) — seule cause nommée par la classification [S1]
- Suspicion : symptômes neurologiques et/ou psychiatriques + sérologie syphilitique positive et/ou IST actuelle ou passée [S11]. Les personnes vivant avec le VIH ont un risque accru, y compris de formes atypiques ou asymptomatiques [S11].
- Paralysie générale (« progressive Paralyse ») = encéphalite chronique progressive : déficits cognitifs, troubles du jugement, épisodes psychotiques, troubles de la parole, céphalées, vertiges, anomalies pupillaires (surtout rigidité pupillaire réflexe, « reflektorische Pupillenstarre »), **tremblement lingual**, « mimisches Beben », crises épileptiques, puis démence sévère, incontinence, marasme [S11].
- Avec sérologie positive et symptômes neurologiques ou psychiatriques : **ponction lombaire** obligatoire (« soll ») [S11].
- Critères DGN/SNG : **probable** = au moins 2 des points (i) évolution subaiguë ou chronique avec aggravations et rémissions partielles, (ii) pléiocytose mixte ou mononucléée et/ou dysfonction de la barrière hémato-méningée, (iii) amélioration sous antibiotiques adaptés — **et toujours** (iv) test de dépistage tréponémique sérique positif confirmé ; **certaine** = probable + production intrathécale d'anticorps anti-*T. pallidum* (index ITpA) ou PCR positive dans le LCR [S11].
- LCR : VDRL du LCR très spécifique (0,95) mais peu sensible (≈ 0,71) — un VDRL négatif n'exclut pas ; critère : VDRL/RPR réactif + leucocytes > 5/µl et/ou protéines > 45 mg/dl ; CXCL13 du LCR utile au diagnostic et au suivi [S11]. Le test TPPA n'est plus disponible ; dépistage par CIA/EIA [S11].
- Traitement : **pénicilline G i.v. à haute dose** (4 × 6 Mio, 5 × 5 Mio ou 3 × 10 Mio UI/j, soit 3–4 Mio UI toutes les 4 h) pendant **14 jours (au moins 10)**, ou **ceftriaxone 2 g/j i.v.** pendant 14 jours (au moins 10) [S11].
- Suivi : clinique ; PL de contrôle à 4–6 mois facultative ; réponse = amélioration clinique, baisse de la pléiocytose et des protéines, baisse du VDRL de 3–4 titres en un an ; PL de contrôle systématique plus recommandée [S11].
- **Suisse** : déclaration par le médecin et le chef de laboratoire **dans la semaine** au médecin cantonal/OFSP [S11].
- FI suisses : benzylpénicilline indiquée dans les infections à spirochètes et la méningite ; injecter lentement au-delà de 2 Mio UI (max. 0,5 Mio UI/min) pour prévenir les troubles centraux ; neurotoxicité à 40–60 Mio UI/j (rein normal), 20 Mio UI (IR légère-modérée), 10 Mio UI (IR sévère) ; flacon 10 Mio UI = 386 mg de sodium [S14]. Ceftriaxone : 1–2 g/j, jusqu'à 4 g ; *T. pallidum* sensible ; **réaction de Jarisch-Herxheimer** possible peu après le début, autolimitée, ne pas interrompre l'antibiotique [S15].

### 5.2 Maladie de Wilson (dégénérescence hépatolenticulaire)
- **Lacune de codage** : le couple CIM (E83.0 et éventuel code de manifestation) n'est pas vérifié à la source.
- Début neurologique typique 20–40 ans (extrêmes 6–72 ans) [S8] ; 5–40 ans, pic 2e–3e décennies [S7]. Les symptômes neurologiques apparaissent plus tard que les hépatiques ; ≈ 50 % des patients neurologiques ont une cirrhose au diagnostic [S8].
- Signes : tremblement (≈ 90 % au cours de la maladie ; jusqu'à 55 % comme premier signe ; tremblement postural « en battement d'ailes »), dystonie 11–65 % (la plus sévère et réfractaire ; rire sardonique, sourire « vacant »), **parkinsonisme 19–62 %**, ataxie ≈ 30 %, chorée 6–16 %, dysarthrie chez presque tous, dysphagie ≈ 50 %, hypersialorrhée ≈ 70 %, troubles de la marche 44–75 % [S8]. La dysarthrie est le signe le plus fréquent au diagnostic [S7]. Présentation monosymptomatique rare [S8].
- Anneau de Kayser-Fleischer : > 90 % (texte) ou > 95 % (tableau) des formes neurologiques [S7].
- IRM : anormale dans > 90 % des formes neurologiques (≈ 40–70 % hépatiques, ≈ 20 % présymptomatiques) ; hypersignaux T2 du putamen 45–85 %, caudé 30–60 %, thalamus 30–60 %, pont 10–80 %, mésencéphale 20–70 % ; atrophie 30–45 % ; une IRM normale n'exclut pas [S8]. Signe de la « face de panda géant » très spécifique mais minoritaire [S7].
- DaTSCAN : ne distingue pas fiablement Wilson et maladie de Parkinson [S8].
- Biologie [S7] : céruloplasmine < 0,10 g/l très évocatrice, 0,10–0,20 intermédiaire, **normale chez 5–20 %** ; cuprurie des 24 h > 100 µg (1,6 µmol) très évocatrice (seuil 40 µg : Se 79 %, Sp 88 %) ; **cuivre échangeable relatif (REC) > 18,5 %** (< 10 % chez témoins et hétérozygotes) ; cuivre hépatique > 250 µg/g.
- **Score de Leipzig** [S7] : KF 2 ; symptômes neuropsychiatriques ou IRM typique 2 ; anémie hémolytique Coombs négative 1 ; cuprurie 1 (1–2 × N) ou 2 (> 2 × N) ; cuivre hépatique −1 (normal), 1 (≤ 5 × N), 2 (> 5 × N) ; céruloplasmine 1 (10–20 mg/dl), 2 (< 10 mg/dl) ; mutations ATP7B 4 (deux allèles) ou 1 (un allèle). **≥ 4 : très probable** ; 2–3 : possible ; 0–1 : improbable. EASL-ERN 2025 recommande le score de Leipzig et, en complément, le REC [S6].
- Traitement : chélateurs (D-pénicillamine, trientine) et sels de zinc ; en atteinte hépatique significative, seuls les chélateurs sont recommandés ; régime pauvre en cuivre ; transplantation hépatique pour l'insuffisance hépatique aiguë wilsonienne, **à discuter aussi dans la forme neurologique** [S6, S9]. Les traitements anti-cuivre améliorent foie et neurologie chez jusqu'à 85 % ; aggravation neurologique à l'instauration chez certains ; amélioration parfois après plusieurs années [S9]. Symptômes persistants chez 40–50 % ; issue défavorable ≈ 20 % [S8].
- Aggravation paradoxale : surtout D-pénicillamine (« ++(+) »), trientine (« ++ »), zinc (« + ») ; en forme neurologique, augmenter la pénicillamine **mensuellement** (au lieu d'hebdomadairement), départ 300 mg/j [S7]. ≈ 30 % arrêtent la pénicillamine pour effets indésirables [S7].
- **FI suisse Cuprior (trientine)** : indiquée chez adultes, adolescents et enfants ≥ 5 ans **intolérants à la D-pénicillamine** ; 450–975 mg/j de trientine base en 2–4 prises (enfant 225–600 mg/j) ; formes neurologiques : augmentation lente, contrôle toutes les 2–3 semaines jusqu'à la dose cible ; aggravation neurologique initiale possible par excès de cuivre libre sérique (dystonie, rigidité, tremblement, dysarthrie) ; prendre ≥ 1 h avant ou 2 h après les repas ; surtraitement → carence en cuivre, anémie sidéroblastique ; suivi au moins 2 ×/an ; cuivre libre normal 100–150 µg/l [S13].
- Symptomatique du parkinsonisme wilsonien : lévodopa ou agonistes dopaminergiques si invalidant (essai de lévodopa conseillé) ; stimulation cérébrale profonde GPi/NST pour cas sévères, pas avant 2–3 ans de traitement anti-cuivre [S8]. Échelle UWDRS (version minimale à 9 items) [S8].
- Dépistage familial : fratrie (risque 25 %) en priorité, parents (mutations en trans), oncles/tantes/cousins ; enfants du cas index après 3 ans [S7].
- Suivi : clinique (UWDRS), bilan hépatique, cuprurie et cuivre échangeable ; défaut d'observance chez près d'un tiers [S7].
- **Lacunes** : D-pénicillamine et zinc (acétate) — aucune FI suisse trouvée par `tools/swissmedic_fi.py` (recherches « penicillamin », « mercaptyl », « wilzin » vides) ; recommandations gradées EASL-ERN 2025 non lues (texte intégral inaccessible).

### 5.3 Hydrocéphalie
- HPN : triade démence, apraxie de la marche, incontinence urinaire, avec ventriculomégalie et pression normale ; **index d'Evans ≥ 0,3** ; aussi angle calleux aigu, bombement du corps calleux, **DESH** [S5] ; angle calleux anormal < 90° [S17]. Bradykinésie et rigidité relativement fréquentes, parfois aux membres supérieurs ; marche et équilibre peuvent s'améliorer après dérivation ; réponse à la lévodopa variable, une réponse franche oriente vers une maladie nigrostriée associée [S5].
- Hydrocéphalie obstructive : parkinsonisme symétrique, parfois paralysie verticale du regard (pseudo-PSP) ; excellente réponse à la dérivation ; aggravation paradoxale possible après dérivation, sensible à la lévodopa [S5].
- **Lacune** : test de soustraction (tap test) et critères de sélection chirurgicale non lus dans une source suisse ou européenne ; codage HPN (G91.2) vs G22\* non vérifié.

### 5.4 Lésions expansives
- Tumeurs : parkinsonisme réversible si compression ; dopaminergiques habituellement inefficaces sauf distorsion mésencéphalique ou perte nigrale [S5]. Irradiation encéphalique totale : parkinsonisme tardif insensible à la lévodopa (leucoencéphalopathie) ; cas après chimiothérapie, inhibiteurs de points de contrôle, amphotéricine B [S5].
- **Hématome sous-dural** : uni ou bilatéral, début subaigu souvent sans traumatisme rapporté, céphalées, troubles cognitifs, signes pyramidaux ; drainage → rémission habituellement complète ; lévodopa inefficace [S5].

### 5.5 Causes métaboliques
- Dégénérescence hépatocérébrale acquise : hypersignal **T1 pallidal** bilatéral (parfois putamen, caudé, substance noire) ; DaTSCAN habituellement normal ; réponse à la lévodopa variable ; amélioration possible après transplantation hépatique [S5].
- Encéphalopathie urémique diabétique : parkinsonisme aigu, œdème lenticulaire bilatéral (« signe de la fourche lenticulaire »), surtout patients asiatiques diabétiques en insuffisance rénale terminale ; amélioration fréquente après hémodialyse [S5].
- Hypoparathyroïdie : calcifications étendues (striatum, thalamus, noyaux dentelés) ; parkinsonisme habituellement insensible à la lévodopa, peut répondre à la normalisation de la calcémie [S5].
- Myélinolyse osmotique (correction rapide d'une hyponatrémie) : évolution biphasique, 2e aggravation après 1–7 jours ; forme extrapontique → parkinsonisme ; IRM en retard de 1–2 semaines, diffusion anormale possible dès 24 h, répéter l'IRM à 2–3 semaines ; traitement de soutien [S5].

### 5.6 Hypoxo-ischémie
- Nécrose pallidale et striatale ; patients plus âgés et latence plus courte que la dystonie pure ; aggravation fréquente après une amélioration initiale (semaines à mois) ; réponse à la lévodopa « possible » [S5].

### 5.7 Infections (hors syphilis)
- **VIH** : instabilité posturale et trouble de la marche, pas de tremblement de repos ; réponse à la lévodopa variable ; IRM normale ou atrophie et atteinte des noyaux gris [S5].
- Encéphalite japonaise : parkinsonisme au réveil, lésions thalamiques bilatérales asymétriques ; West Nile : surtout transitoire ; *M. pneumoniae* : nécrose striatale bilatérale de l'enfant et du jeune adulte, récupération spontanée habituelle ; SARS-CoV-2 : IRM normale ou non spécifique [S5].
- Toxoplasmose (lésions en cocarde des noyaux gris), cryptococcose, HHV-6 [S5].
- **Creutzfeldt-Jakob** : progression rapide, déclin cognitif, myoclonies ; hypersignaux diffusion/FLAIR, ruban cortical (sporadique), signes du pulvinar et de la « crosse de hockey » (variant) [S5]. Suisse : formes sporadique, génétique, iatrogène ; maladie toujours mortelle, sans traitement ; formulaires de déclaration OFSP ; centre national de référence des maladies à prions (NRPE, Hôpital universitaire de Zurich) [S12].

### 5.8 Causes immunes
- Encéphalites auto-immunes et paranéoplasiques : anti-Ma2 (jeune homme, tumeur germinale testiculaire ; paralysie verticale pseudo-PSP ; ≈ 1/3 répond partiellement au traitement tumoral et immunitaire), anti-Ri (femme, cancer du sein), CRMP5 (pseudo-PSP), NMDAR (parkinsonisme surtout chez l'enfant), LGI1, CASPR2, IgLON5 ; une IRM normale n'exclut pas ; **immunothérapie précoce** car traitables [S5].
- Lupus : surtout jeunes femmes ; dopaminergiques inefficaces, corticoïdes et immunosuppresseurs efficaces ; Sjögren : début moyen 60 ans, réponse aux corticoïdes ; syndrome des antiphospholipides : infarctus thrombo-occlusifs irréversibles, lévodopa inefficace [S5].
- Sclérose en plaques : association habituellement fortuite ; rarement démyélinisation thalamique, pallidale ou nigrale avec réponse aux corticoïdes [S5].

## 6. Anamnèse

- Médicaments et toxiques (pour exclure G21), antécédents d'encéphalite, de traumatisme crânien [S16].
- Rythme : aigu (AVC, myélinolyse, encéphalopathie urémique, hypoxie), subaigu (hématome sous-dural, neurocysticercose, auto-immun), chronique (HPN, Wilson, hépatopathie) [S5].
- Terrain : hépatopathie ou shunt porto-systémique [S5] ; âge jeune et hépatopathie ou troubles psychiatriques → Wilson [S7, S8] ; IST, VIH [S11] ; cancer connu [S5] ; correction de natrémie récente [S5] ; chute ou anticoagulation (hématome) — **Lacune** pour le facteur anticoagulation (non lu).

## 7. Examen clinique

- Confirmer le parkinsonisme (bradykinésie à décrément + rigidité et/ou tremblement de repos) [S16, S18].
- Symétrie, prédominance axiale ou aux membres inférieurs, tremblement de repos présent ou absent [S5].
- Signes associés orientant : anneau de Kayser-Fleischer, dystonie, dysarthrie (Wilson) [S7, S8] ; anomalies pupillaires, troubles cognitifs (neurosyphilis) [S11] ; paralysie verticale du regard (hydrocéphalie obstructive, anti-Ma2, CRMP5) [S5] ; myoclonies et déclin rapide (prions) [S5] ; signes pyramidaux, céphalées (hématome sous-dural) [S5] ; cécité (méthanol) [S5].
- Drapeaux rouges contre la maladie de Parkinson (HUG d'après MDS) : chutes précoces, dysautonomie précoce, syndrome cérébelleux, pyramidal, troubles oculomoteurs, troubles cognitifs précoces, parkinsonisme symétrique à prédominance des membres inférieurs [S17].

## 8. Examens complémentaires

- **IRM cérébrale** : examen central ; elle peut désigner directement la cause, à interpréter dans le contexte clinique [S5] (signes : T1 pallidal = manganèse/hépatopathie ; T2 putamen-thalamus-tronc = Wilson ; Evans ≥ 0,3/DESH = HPN ; fourche lenticulaire = urémie diabétique ; diffusion corticale/ruban = MCJ ; nécrose putaminale = méthanol ; pallidale = CO) [S5, S8].
- **DaTSCAN** : normal dans la plupart des dégénérescences hépatocérébrales [S5] ; ne sépare pas Wilson et Parkinson [S8] ; indication FI suisse : perte des terminaisons dopaminergiques dans les syndromes parkinsoniens cliniquement douteux [S19].
- Biologie ciblée : céruloplasmine, cuprurie 24 h, cuivre échangeable/REC, génétique ATP7B, examen à la lampe à fente (Wilson) [S6, S7] ; sérologie syphilitique (CIA/EIA + confirmation), VIH [S11] ; calcémie/PTH (hypoparathyroïdie) [S5] ; tests hépatiques, ammoniémie — **Lacune** (ammoniémie non lue).
- **Ponction lombaire** : neurosyphilis (cellules, protéines, Reiber, ITpA, VDRL, CXCL13) [S11] ; encéphalite auto-immune, MCJ — **Lacune** (protéine 14-3-3/RT-QuIC non lus).
- Angiographie : référence pour la fistule durale [S5].

## 9. Diagnostic différentiel

- Maladie de Parkinson (G20) ; parkinsonisme médicamenteux, toxique, vasculaire, post-encéphalitique (G21) ; parkinsonismes atypiques (PSP, AMS, DCB, démence à corps de Lewy) [S4, S17].
- Mimiques fonctionnelles ou psychiatriques (3,8 % des non dégénératifs à Genève) [S4].

## 10. Urgences

- Hématome sous-dural (drainage) ; myélinolyse osmotique (prévention par correction lente) ; insuffisance hépatique aiguë wilsonienne (transplantation) ; neurosyphilis (antibiothérapie i.v.) ; encéphalite auto-immune (immunothérapie précoce) [S5, S6, S11].

## 11. Prise en charge (principes, Suisse/Europe)

1. **Traiter la cause** : beaucoup de formes régressent après suppression de la cause [S5] (drainage, dérivation, dialyse, transplantation, antibiotiques, immunothérapie, correction calcique).
2. **Essai de lévodopa** : utile si atteinte présynaptique nigrostriée ; à tenter dans le manganisme malgré des réponses souvent faibles (8/13 mineurs chiliens améliorés, séries ultérieures surtout négatives) [S5] ; Wilson : essai conseillé [S8].
3. Wilson : anti-cuivre à vie, titration prudente en forme neurologique [S7, S13].
4. Neurosyphilis : pénicilline G i.v. 14 j ou ceftriaxone [S11, S14, S15] ; déclaration OFSP [S11].
5. **Lacune** : aucune recommandation suisse dédiée au parkinsonisme secondaire « classé ailleurs » trouvée (SNG, Swiss Medical Forum).

## 12. Suivi

- Wilson : clinique, UWDRS, foie, cuprurie, cuivre échangeable ; ≥ 2 fois/an sous trientine [S7, S13].
- Neurosyphilis : clinique ; VDRL sérique (baisse de 3–4 titres en un an) ; PL facultative à 4–6 mois [S11].
- Myélinolyse : IRM de contrôle à 2–3 semaines [S5].

## 13. Situations particulières

- **Enfant** : parkinsonisme d'anti-NMDAR surtout pédiatrique ; *M. pneumoniae* ; irradiation pallidale ; Wilson dès 2 ans [S5, S7]. Trientine dès 5 ans [S13].
- **Grossesse (Wilson)** : poursuivre le traitement, ajuster la trientine pour une cuprémie normale, éviter la carence fœtale en cuivre [S13].
- **VIH** : risque accru de neurosyphilis atypique ; PL systématique sans symptôme neurologique plus recommandée [S11].
- **Insuffisance rénale** : neurotoxicité de la pénicilline G à doses plus basses [S14] ; ceftriaxone ≤ 2 g/j si clairance < 10 ml/min [S15].

## 14. Critères formels du diagnostic (pour `div.alert`)

- G22\* = parkinsonisme (bradykinésie + rigidité et/ou tremblement de repos) [S5, S18] **imputable à une maladie codée ailleurs**, codé **après** le code étiologique (†), jamais seul [S1, S3].
- Neurosyphilis probable/certaine : critères DGN/SNG (i)–(iv) ; certitude par ITpA ou PCR du LCR [S11].
- Wilson : score de Leipzig ≥ 4 [S7] (+ REC selon EASL-ERN 2025 [S6]).

## 15. Paramètres clés (pour `div.key`)

- Parkinsonismes non dégénératifs à Genève : 20 % [S4].
- Wilson : prévalence ≈ 1/30 000 ; parkinsonisme 19–62 % des formes neurologiques ; IRM anormale > 90 % ; KF > 90 % ; céruloplasmine normale 5–20 % ; REC > 18,5 % ; Leipzig ≥ 4 [S7, S8].
- HPN : index d'Evans ≥ 0,3 [S5].
- Dégénérescence hépatocérébrale : 1–2 % des hépatopathies chroniques [S5].
- Neurosyphilis : pénicilline G 24–30 Mio UI/j (4 × 6, 5 × 5 ou 3 × 10 Mio UI ; ≈ 3–4 Mio UI/4 h) ou ceftriaxone 2 g/j, 14 j (≥ 10) [S11].
- MCJ en Suisse : 10–15 cas/an [S12].

## 16. Lacunes récapitulées

1. Règles suisses de codage †/\* (Manuel OFS) non lues ; rattachement à G22\* vérifié pour la seule syphilis.
2. Aucune source décrivant la sémiologie propre du parkinsonisme syphilitique.
3. EASL-ERN 2025 : texte intégral inaccessible ; recommandations gradées neurologiques non lues.
4. FI suisses de la D-pénicillamine et du zinc introuvables via l'outil.
5. HPN : tap test et sélection chirurgicale sans source suisse/européenne lue.
6. MCJ : critères diagnostiques (14-3-3, RT-QuIC) non lus.
7. Incidence suisse de la syphilis non lue.
8. Recommandation suisse dédiée (SNG, SMF) non trouvée.
9. S16–S19 repris du dossier G21, non relus dans cette session.
