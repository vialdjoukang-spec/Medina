Pourquoi les déclencheurs diffèrent

Le courant IKs, déficitaire dans le type 1, est celui que la stimulation adrénergique renforce pour raccourcir le potentiel d’action à l’effort : sans lui, le QT ne raccourcit pas quand la fréquence monte, et 62 % des événements surviennent à l’effort. Dans le type 2, une décharge adrénergique brutale survient sur une repolarisation privée d’une partie de IKr. Dans le type 3, le courant sodique tardif pèse surtout aux fréquences lentes : 39 % des événements surviennent au repos ou pendant le sommeil (Schwartz et al., 2001).

Pourquoi la surdité

Le canal formé par KCNQ1 est aussi exprimé dans la strie vasculaire de l’oreille interne, où il contrôle probablement la composition de l’endolymphe ; quand les deux allèles sont atteints, l’audition et la repolarisation sont toutes deux défaillantes (Neyroud et al., 1997).

Risque : des associations

Avant 40 ans et sans traitement, un premier événement touchait 30 % des porteurs d’un type 1, 46 % d’un type 2 et 42 % d’un type 3 ; le QTc prédisait le risque dans les types 1 et 2, le sexe seulement dans le type 3 (Priori et al., 2003). Ces facteurs désignent les patients à surveiller de près ; ils ne décident pas seuls d’un DAI.
